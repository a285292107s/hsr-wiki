# 研究线迁入主站 dev-only 路由（Spine Lab 独立子应用 → /debug）

## Status: accepted

## Context

研究线（Spine Lab）自独立 Vite 子应用起步（`pnpm dev:lab` → 5174，与主项目双向隔离，见 docs/agents/architecture.md）。独立应用带来双重成本：开发需同时起 5173/5174 两个 dev server，且研究线入口需单独开页面，与主站产品割裂。zzz wiki 已实践「研究/调试页 = 主站 dev-only 路由」（`import.meta.env.DEV` 注册，生产构建摇树，prod 零打包、深链落 404）。

用户决定参照该模式把研究线迁入主站：主站侧栏「调试台」入口（≥768px 平板/桌面显示，设置按钮上方）指向主站内 dev 路由 `/debug`，生产构建不含研究线。

## Decision

1. **视图迁入主站**：`spine-lab/src/*` 迁移至 `src/app/debug/`（`App.vue` → `DebugConsoleView.vue` 作为 `/debug` 路由组件；四功能面板 + 引擎 + lib/query-state + lib/toast + system-map 全量迁入）。相对导入 `../../src/x` → `../../x` 机械改写。研究文档 `spine-lab/docs/` 与研究脚本 `spine-lab/tools/` 保留（非应用资产）。
2. **dev-only 注册（构建级摇树）**：路由在 `router/index.ts` 的 `createNkRouter()` 内 `if (import.meta.env.DEV) router.addRoute(...)`；侧栏「调试台」入口在同文件 `const IS_DEV = import.meta.env.DEV` + `v-if`。
   - **坑位（实测）**：Vue 模板内**不能**写 `import.meta.env.DEV`（模板编译器报 `import.meta may appear only with 'sourceType: "module"'`）；跨模块 `export const IS_DEV` + 数组展开分支**不能**消除 dynamic import（Rollup tree-shaking 边界不跨模块）——必须各自**本文件内**写 `import.meta.env.DEV` 常量替换 + `if(DEV)` / `v-if` 分支才真正摇树。
   - 摇树结果：prod 无 `/debug` 路由（深链落 404）、无研究线视图 chunk；仅侧栏 vnode 恒 false 分支残留（~150B，与 zzz wiki 同量级，接受）。
3. **CDN 健康探测**：原 lab `main.ts` 自启 `startCdnHealthProbe`——主站 bootstrap 已全局启动并订阅提示，/debug 不再重复启动。
4. **Toast 桥接**：原 lab 自建 toast 宿主（无 Pinia 依赖）删除，`lib/toast.ts` 改为桥接 `useAppStore().toast`（主站全局 ToastHost 常驻渲染）。debug 目录内调用面（`toast(type, message)` 签名）不变。
5. **dev 中间件并入主 vite.config**：lab 的 data-file-index 插件（dev 暴露 `/data/cn/data-file-index.json`，死链审核浏览器端 URL 清单源）并入主 vite dev server；生产不需要（/debug 不打包，`generateBundle` emit 移除）。
6. **样式**：lab 自建 `styles/base.css`（自建同值令牌）删除——主站 tokens.css 已覆盖其全部 54 个引用变量（实测 comm 为空）；`.nk-spine-debug` 页面套主站文档流骨架：≥768px `margin-left: var(--nk-content-offset)` 避让侧栏，手机保留原底部栏避让（页面级 overflow-x auto 即可，lab 各 section 内部滚动块保持不变）。
7. **侧栏入口（≥768px）**：设置按钮上方、`ui-sidebar-link ui-sidebar-debug`（图标 + 中文「调试台」/ 英文「DEBUG」）。手机（<768px）`display:none` 且**不参与底部栏动态折叠测量**（SidebarNav recomputeFold 的 navW 与 DOM 槽位均显式排除 `.ui-sidebar-debug`，保持与 navItems 对齐）。
8. **色彩守卫豁免演进**：`check-colors.mjs` SKIP_FILE 由逐文件豁免（SpineKvSection/SpineAuditSection/…，旧 src/debug 残留）改为豁免 `debug/` 整目录——研究线诊断面板状态色（ok/fail/warn 研究工具语义）不属产品 UI 令牌体系。
9. **测试并轨**：lab 4 套 `__tests__`（dead-links/kv-acceptance/spine-audit/use-kv-acceptance + system-map/map-data）迁入主 `src/app/debug/__tests__`，并入主 `pnpm test`（vitest include `src/**/__tests__`）。独立 `test:lab` / `dev:lab` / `build:lab` 命令与 `spine-lab/` 应用壳（index.html / vite.config / tsconfig / vitest.config / dist / node_modules）删除。
10. **文档/裁决同步**：AGENTS.md 命令区 + architecture.md「研究线」节更新；本 ADR 记录决策。

## Considered Options

- **保持独立 5174 子应用，侧栏外链打开**：改动最小，但保留双 dev server + 隔离架构成本，且「调试台」与主站产品割裂。被拒——用户拍板迁入主站。
- **dev 路由但视图仍放独立目录 + 独立构建**：无意义折中。被拒。
- **跨模块 IS_DEV + 数组展开分支注册路由**：代码更「干净」，但实测无法消除生产 dynamic import（研究线 chunk 79KB 进产物）。被拒——选用实测可行的本文件内 `if(import.meta.env.DEV)` 模式。

## Consequences

- 开发体验：`pnpm dev` 单 server，`http://localhost:6188/debug` 直达研究线，侧栏（≥768px）「调试台」入口。生产：无 `/debug` 路由（404）、零研究线代码打包。
- 主站 `pnpm test` 增加 72 例（336 总）；e2e layout 桌面断点含「调试台」入口断言（e2e 全程 dev server）。
- Playwright 桌面 4 张像素基线（home/character/endgame/currency）因侧栏新增按钮需本机刷新（`pnpm test:e2e:update =all`）。
- 手机（<768px）无「调试台」入口（底部栏无空间）；直接访问 /debug 仍可查看。
- 历史：旧 `src/debug/`（更早的调试面板家）→ spine-lab/（2024 独立化）→ 主站 src/app/debug/（本次回迁）——两次迁移后代码收敛于主站 dev 路由，研究文档仍留 spine-lab/docs。
