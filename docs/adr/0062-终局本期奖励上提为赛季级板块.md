# 0062. 终局奖励上提为页面底部的赛季级「本期奖励」板块

> **修订**：[ADR 0051](0051-终局赛季奖励进详情页.md) 补记六（奖励板垫在关卡面板底部）——奖励不再属于任何关卡 tab，改为页面级一次渲染。

## 状态

`accepted`（**已实现**：新增 `EndgameSeasonRewards.vue` + `season-rewards.ts`；`EndgameFloor` / `EndgameTierce` / `EndgamePeak` 移除 `nk-egd-head` 奖励板（**连同其「通关条件」格**），关卡 tab 只留挑战内容；`EndgameView` 在关卡面板之后、相邻赛季导航之前渲染 `<EndgameSeasonRewards>`；`EndgameStarTierList` 增 `hideLabel`；`.nk-egd-head` 网格、`.nk-egd-lvl__rules` 与 `.nk-egd-peak__body > .nk-egd-head` 等死样式同批删除；i18n 新增 `egd.seasonRewards`；e2e 的奖励断言迁移到 `#egd-season-rewards`；**2026-10-19 补记：统一赛季压缩（共享头 + 完整阶梯）**）

## Context

用户提问「奖励是否都是赛季层级的？是否应该把奖励面板从关卡 tab 中提出来，重新编排，展示页面底部」。逐项核对四份产物的层级归属：

1. **星级奖励是赛季级**：每期一条累计阶梯（忘却之庭 12 档 3..36、虚构叙事 / 末日幻影 12 档 1..12、异相仲裁骑士 3/6/9 + 王棋 1/2/3 + 绝境 3）。层 tab 里看到的「本层切片」是转换器 `_season_floors` 按层序切的**展示**，不是每层各有一条奖励线。
2. **星启奖励是赛季级**：13 期各一份（通关奖励 8 项 + 棱彩奖励 3 项，除勋章外跨期同载荷）。
3. **逐层通关奖励是层级级**：每层一条 `Challenge*MazeConfig.RewardID`；但载荷几乎逐层相同——忘却之庭 55/57 期同载荷、虚构叙事 27/27、末日幻影 22/22；例外是忘却之庭 `100`（2 种载荷，且回合上限 20/30）与 `900`（2 种载荷）。
4. **条件/目标也是层级级**：虚构叙事 / 末日幻影各层目标逐期一致；忘却之庭当前 1033–1036 一致，但老期 `100–119`、`1001–1006` 逐层不同（2–3 种目标签名）。异相仲裁每关目标独立（骑士 4/2/无死亡、王棋 6/4/2、绝境 2）。

结论：**奖励的 payout 主体是赛季级，条件与逐层通关奖励是层级级**。原面板把两类混在「通关条件｜通关奖励 / 星级奖励」里，且每个层 tab 重复渲染同一份赛季级信息（12 个层 tab = 12 次），切 tab 还会重新渲染。

## Decision

1. **奖励与通关条件成对上提**：`nk-egd-head` 从三个面板组件移除（含「通关条件」格）；关卡 tab 只留挑战内容（卡片行 + 看板）。`通关条件` 与 `通关奖励` 是同一组「完成条件 → 领取奖励」的事实，必须相邻出现，不能一个留 tab、一个去页底；两者一起进页底对应层组，关卡 tab 里由半场卡片的「回合」行承担实战时最需要的回合上限。
2. **页面底部「本期奖励」板块**：`EndgameView` 在 `EndgameLevelPanel` 之后、`nk-egd-nav` 之前渲染一次 `EndgameSeasonRewards`；`id="egd-season-rewards"`，标题取新词典键 `egd.seasonRewards`。
3. **按层/按关分组，不做扁平阶梯**：组序 = 层 1..N → 星启模式（有 `tierce` 时）；异相仲裁 = 骑士（一/二/三）→ 王棋 → 绝境。每组含该层/关的「通关条件 | 通关奖励」两栏与该层星级切片（档位徽章 + 条件 + 奖励 chips）。**用分组而不是一条扁平阶梯**，是为了保住老期逐层不同的条件与 `maze 100/900` 的逐层载荷例外，不需要额外的例外表，也不把层级事实压成赛季事实。
4. **逐层通关奖励与通关条件全部进页底组**：不在层 tab 留副本（同一事实只出现一次）；页底组按层自包含，用户按层查找。
5. **渲染与数据**：分组纯函数 `seasonRewardGroups(data)` 放 `season-rewards.ts`（只消费现有产物字段，转换器零改动）；`EndgameReward` / `EndgameStarTierList` 复用，星数列表在组内隐藏自身栏名（`hideLabel`），由组标题承担。
6. **不引入棱彩星图标**：图标资产（`SpriteOutput/UI/Abyss/Tierce/ChallengeTierceModeStarColor.png`）已在 StarRailTextures / CDN 可用，但本轮只做编排，图标接入留在后续单点决策。

## Consequences

**正面**

- 赛季级奖励只渲染一次：切层 tab 不再重渲染同一份奖励，层 tab 更短、更聚焦于「这一层打什么」。
- 完整的按层奖励在一个位置可顺序读完（忘却之庭 13 组、虚构 / 末日 5 组、异相仲裁 5 组），不再需要逐 tab 拼装。
- 老期条件差异与 `maze 100/900` 的逐层载荷例外天然保留，无扁平化损失。
- 奖励板内「星级奖励」的棱彩星行共列修复（分组内仍走 `.nk-egd-tiers--prism` 共享列）继续生效。

**负面**

- 页底板块显著变长：忘却之庭 1035 实测约 3,584px（13 组），虚构 / 末日约 1,595px，异相仲裁约 885px（1440 视口）。这是「一层一组」的必然代价；若后续要缩短，需在「同载荷省略 / 两列组网格 / 折叠」中另做裁决。
- 逐层通关奖励与「通关条件」一起离开层 tab：看某一层的条件与奖励要多滚到页底；层 tab 不再回答「这层什么条件通关、给什么」。缓解：忘却之庭 / 虚构叙事的半场卡片已有「回合」行，异相仲裁单关面板的敌方等级在卡片上；页底组仍按层自包含，条件与奖励相邻。
- e2e 的奖励断言从 `#egd-level-panel .nk-egd-head` 整体迁移到 `#egd-season-rewards`；`layout-endgame-board*` / `layout-endgame-season` 三份 spec 同步改写。
- ADR 0051 补记六的「奖励板垫底」表述被本条修订为「赛季级奖励板块垫底」。

**中性**

- 转换器 / 产物 / AI 快照零变化（快照来自 catalog 轻量条目）。
- 页底板块的标题与组标题只新增 1 个词典键（13 语言）。
- 页底板块在 `unpublished` 赛季不渲染（与关卡 tab 同一 `v-if` 分支）。

## Alternatives considered

| 方案 | 为何未采用 |
|---|---|
| 扁平赛季阶梯（一档一行） | 更短，但老期逐层条件（`maze 100–119` / `1001–1006`）与 `maze 100` 的 20/30 回合无处安放，必然要「条件随层」注记或例外表 |
| 只上提星级 / 星启 / 异相仲裁奖励，逐层通关奖励留 tab | 奖励仍分散两处、层 tab 仍有奖励块；与「把奖励面板提出来」的目标只完成一半 |
| 维持奖励板在层 tab 底部（ADR 0051 补记六） | 赛季级信息重复 4–12 次，切 tab 重渲染；用户已明确要求上提 |
| 把页底板块做默认折叠 | 奖励是查询型信息，默认折叠会让「本期奖励」不可见；先按常开落地 |

## 补记（2026-10-19：统一赛季压缩 —— 共享头 + 完整阶梯）

用户反馈页底板块过长，且「很多层的奖励其实是一样的」。全量核对：

- 虚构叙事 **27/27**、末日幻影 **22/22**、忘却之庭 **30/57** 的「逐层通关奖励 + 通关条件 + 挑战目标」三层完全一致；非一致的 27 个忘却之庭赛季（`100` / `900` / `101–119` / `1001–1006`）是奖励 1–2 种、回合 1–2 种或目标 2–3 种。
- 统一赛季里每层真正不同的只有星级档位（3★/6★…）与该档奖励数值；通关奖励、回合/分数线、三条挑战目标逐层重复。

决策：新增 `seasonRewardPlan(data)` 的**统一快速路径**：

1. **判定**：所有层 `reward` 载荷、`floorRules`、`targets` 签名三者全同（且存在赛季 `star_rewards`）⇒ 统一路径；否则回退现有按层分组（`maze 100/900`、老期）。
2. **统一路径版式**：共享「通关条件 | 通关奖励」一次 + 「第 1–N 层适用」注记 + 左侧共享挑战目标 + 右侧完整星级阶梯（一档一行，徽章 + 奖励，不再逐层重复条件）；星启模式仍作独立组。
3. 新增 `EndgameSeasonRewardGroup.vue`（组渲染复用给星启与回退组）；`EndgameSeasonRewards.vue` 分统一/回退两支；新词典键 `egd.rewardScope` / `egd.starRewards`。
4. 不改数据、不改转换器、不改 AI 快照；`seasonRewardGroups` 保留为回退与 DOM 测试口径。

实测（1440 / 390）：

- 忘却之庭 1035：4,182 → **1,262**（-70%）；390：7,913 → **3,187**（-60%）。
- 虚构叙事 2027 / 末日幻影 3021：1,825 → **1,290**（-29%）；390：4,816 → **3,547**（-26%）。
- 异相仲裁 10：885 不变（王棋三档目标逐档不同；骑士三关虽同，但页底本就短，暂不压缩）。
- `maze 100` / `900` / 老期：仍走按层分组，保留逐层条件与载荷例外。

测试：`season-rewards.test.ts` 增统一 / 回退 / peak 三条；e2e 的 maze 1035 / story 2026 / boss 3021 改为统一路径断言，`maze 100` 保留回退断言；peak 与 a11y 不变。
