# 详情页多语言名称事实行与 JSON-LD 别名数组

**Status**: Accepted（决策已定；正文侧实现未落地，前置条件未闭合）

> 本 ADR 只裁两件事：**缺省语言（cn）条目级详情页正文新增一行「多语言名称」事实行**，以及**该实体 JSON-LD 的 `alternateName` 由单值字符串改为数组**。
> 它**不改语言分层**：条目级详情页仍只做缺省语言快照（[ADR 0052](0052-多语言站点架构-路径前缀与语言包.md) 决策 6 / 用户裁决 B）。
> **前置条件未闭合**：该行须由前端详情页同源渲染（见「与快照契约的关系」）；未闭合前不得只落快照。

## Context

纯 CSR + 语言分层叠加后的实测后果：

- `/en/character/1308`、`/jp/character/1308` 这类**非缺省语言的条目级页面**返回 200 的空壳 `_shell.html`（3,052 字节、无正文）——在无 JS 抓取方看来它们不存在。
- `/character/1308`（黄泉）的 cn 快照正文里 `Acheron` 出现 **0** 次；该串只存在于 JSON-LD 的 `Person.alternateName`（单值字符串，来源是结构层字段 `name_en`，生成器 `tools/gen-ai-endpoints.mjs:680`）。
- ⇒ 跨语言 query（`Acheron` / `黃泉` / `아케론` / `Ахерон` / `Achéron`）在**条目级**实体上没有任何可命中正文，目前只能命中 12 个非缺省语言前缀的目录页（19 条路由 × 12 语言 = 228 份分层快照）。
- 官方译名数据**已存在且生成器已在读**：`public/data/i18n/<lang>/<分组>.json`（13 个语言目录，cht/cn/de/en/es/fr/id/jp/kr/pt/ru/th/vi），构建期合并入口 `packOf()`（`tools/gen-ai-endpoints.mjs:49`）⇒ 本决策**不新建数据源**。
- 实测同一令牌 `15302882570557665677`（`public/data/cn/characters/1308.json` 的 `name`）在 13 个语言包里的取值：

| 语言 | 取值 | 备注 |
| --- | --- | --- |
| cn | 黄泉 | 缺省语言主名（= 页面 H1 / LD `name`） |
| cht | 黃泉 | 繁体字形，与 cn 不同码点 |
| jp | 黄泉 | 与 cn **逐字相同** |
| kr | 아케론 | |
| ru | Ахерон | |
| fr | Achéron | |
| de / en / es / id / pt / th / vi | Acheron | 与 `name_en` 逐字相同 |

⇒ 13 个取值里只有 5 个不同字形：**「多语言」不等于「多字形」**，事实行必须按字形折叠，不能逐语言照抄。

代价面（实测）：`dist/prerender` 1432 份 / `dist` 总 352.6 MB；把条目级详情页族按 13 语言展开需再增约 1.5 万份快照（估算）。

## Decision

1. **cn 条目级详情页正文新增一行「多语言名称」事实行**，与该页既有事实表同容器、同形态。取值 = 该实体 H1 主名令牌在**各非缺省语言包**里的值，**逐字取自** `public/data/i18n/<lang>/**.json`，不加工、不润色、不翻译。
2. **适用范围判据（家族无关，免逐族裁决）**：凡详情页 H1 主名在结构层是 `$t:<TextMap 键>` 令牌、且该键在至少一个非缺省语言包里有非空值者 ⇒ 出该行；主名非令牌（如开拓者的 `{NICKNAME}` ⇒ 空串）或 12 个非缺省语言全部缺键 ⇒ **整行省略**。角色 / 光锥 / 遗器 / 敌对物种 / 终局赛季 / 货币战争条目按同一函数自动覆盖。
3. **折叠规则**：与 H1 主名（当前语言主名）**逐字相同**的取值不出现在行内——同一字形不构成另一语言的事实。实测锚点：jp「黄泉」被折叠、cht「黃泉」保留。折叠作用于**取值集合**，不是删语言数据。
4. **顺序与标签**：语言序取语言清单单一事实源（转换器侧与前端侧由 `tools/check-languages.mjs` 逐项比对），**禁止**两端各自写死；语言标签与分隔符措辞取 UI 词典，**禁止**在生成器里写死中文标签。
5. **JSON-LD `alternateName` 由单值字符串改为数组**：内容 = 官方译名的**去重字符串集合**（含既有 `name_en`），主名 `name` 不重复进数组；不排序、不改写、不标注语言。本轮作用域 = 已挂该属性的角色详情页 LD（`ldCharacter`）。
   - schema.org 的 `alternateName` 是 `Thing` 域、期望类型 `Text`（已核 `https://schema.org/alternateName`）⇒ 同判据可顺延到 `Thing` 类数据条目页（光锥 / 遗器 / 敌对物种 / 终局赛季）。**该顺延本轮不裁**，记为待裁决项，避免把「属性可挂」当成「必须挂」。
6. **落点不变（硬边界）**：不新增路由、不改 URL 形态、不改快照与 `sitemap` 份数、不动语言包结构、不动 `$t:` 令牌协议。该行只进**缺省语言**的条目级详情页快照。

## 「文本必须来自数据」的合规性

读官方语言包**不构成第二事实源**，判据是「同一令牌键」：

- 结构层实体名是文本引用令牌（实测 `public/data/cn/characters/1308.json` 的 `name` = `$t:15302882570557665677`），语言包是该**同一键**在另一语言的取值；两者由同一次转换、同一份 TextMap 键空间产出（见 [ADR 0052](0052-多语言站点架构-路径前缀与语言包.md) 决策 2），前端解析入口 `src/services/api/local.ts`、构建期解析入口 `packOf()`，读的是同一批 `public/data/i18n/<lang>/**.json`。
- 本事实行取的正是「H1 主名令牌 → 各非缺省语言包的值」，与页面主名**同一条链**，只是多取 12 个语言 ⇒ 不是「另起一份译名表」，而是同一事实在语言维度上的展开。
- 禁令（可判定）：
  - 禁止手写 / 机翻 / 推断译名（与 [ADR 0039](0039-角色拉丁转写名由转换器写入.md) 的「禁自造译名」同纪律）；语言包缺键即该语言缺席，不兜底、不留 `?`。
  - 禁止按实体 id 白名单硬编码该行（镜像 [ai-discoverability.md](../agents/ai-discoverability.md) §3 对 `invaded` 判据的禁令）。
  - 禁止两端各写一份语言清单 / 语言序 / 标签表。
  - 禁止在生成器里写死中文标签（[ADR 0052](0052-多语言站点架构-路径前缀与语言包.md) 决策 6）。

## 与快照契约的关系（前置条件，未闭合）

[ai-discoverability.md](../agents/ai-discoverability.md) §3 的对齐判据：**实体级事实标签必须与页面逐字一致**（`<h1>`、实体名、`受『贪饕』侵蚀` 这类事实行、一切数据派生文本）。

结论：**这一行必须由前端详情页同步渲染**——措辞、取值集合、语言序、分隔与折叠规则与快照**同源同判据**。只进快照会造出「页面没有的事实行」，同时破坏 §3 的对齐判据与「快照不得成为第二事实源」的既有纪律。

因此本 ADR 把「前端 cn 详情页渲染同一行」列为**前置条件**，并明确：**未闭合前，正文侧不得只落快照**。本 ADR 不假装该条件已完成。

前置条件里尚未裁决的子问题（**待用户裁决**）：SPA 如何在详情页拿到 12 个非缺省语言的实体名，而**不加载 12 个分组语言包**（该类包单语言数 MB 级，[ADR 0052](0052-多语言站点架构-路径前缀与语言包.md) 决策 2 的「按数据集懒加载」前提）。候选：

- (i) 转换器新增一件「实体名 × 语言」小产物（新增产物 = 跨模块契约，须在转换器侧登记并接 `src/services/api/*`）；
- (ii) 前端按实体现取所在分组包（成本与本决策收益不成比例，倾向否决）。

## 替代方案（被否）

- **(a) 条目级详情页也按 13 语言全量预渲染**（补「真·多语言详情页」，单看收益大于事实行）。否决：① 成本——快照再增约 1.5 万份（在 1432 份 / `dist` 352.6 MB 之上），`sitemap` / rewrite / hreflang 面同步扩张，hreflang 为「13 语言 + x-default」× 每条目；② 与用户裁决 B 正面冲突——条目级只做缺省语言是**用户裁决**，不是本 ADR 能自行改写的取舍；③ 13 份快照正文近乎逐字相同、只有实体名不同 ⇒ 制造近重复页，收录收益被 hreflang 与重复内容治理成本抵消。**本轮不做；若「跨语言详情页本体」成为目标（而非「跨语言 query 可命中该实体」），须用户重新裁决并单开 ADR。**
- **(b) 只把 LD `alternateName` 改数组、正文不加行**：零展示风险（不动页面、不触 §3 对齐判据、无前端取数成本），但正文抽取型管线看不到。本站实测的可见性决定性因素是**服务端 HTML 正文**，而 [ai-discoverability.md](../agents/ai-discoverability.md) §4 明确 LD 的价值是「富结果与实体消歧，不是 AI 引用杠杆」（Ahrefs 1,885 页 DiD 无引用提升）⇒ 作为**唯一手段**收益≈0。**否决为唯一手段；数组本身零成本且是消歧信号，作为本决策的附带项保留。**
- **(c) 维持现状**：跨语言 query 只能命中 12 个非缺省语言前缀的目录页，条目级实体在无 JS 抓取下对非中文 query 不存在——这正是本 ADR 要解决的问题，零收益。
- **(d) 自建译名表 / 机翻补缺**：直接违反「文本数据来源」硬约束与禁止自造译名的既有纪律，并制造第二事实源。**禁止，不列为待裁决项。**
- **(e) LD 用带语言标签的对象形（`{"@value":…, "@language":<culture>}`）替代纯字符串数组**：能保留语言归属、无需去重、可区分 cht/jp 的同字不同语言。否决：对「实体消歧」这一用途无增量（同一字形重复不增加可匹配面），却把形状从 `string[]` 变成 `object[]`，多语言消费方与断言面全部要重估。判据不变时随时可复评。

## 后果

### 正面

- 跨语言 query（`Acheron` / `黃泉` / `아케론` / `Ахерон` / `Achéron`）首次可在 cn 详情页**正文**命中，且不新增任何可索引 URL。
- 无新增数据源：取值全部来自既有语言包的同一令牌键，零转换器字段改动。
- LD `alternateName` 成为去重后的官方译名集合，提升实体消歧（**不承诺**引用/排名收益）。

### 负面 / 留账

- **双写面 +1**：同一行须在「cn 详情页快照」与「前端 cn 详情页」两处逐字一致；措辞、语言序、分隔、折叠规则任何一处改动都要同批改两处（§3 的对齐判据新增一个比对点）。
- **前端取数成本未解**：见「与快照契约的关系」的待裁决子问题；这是本决策最大的未闭合面。
- **汉字棘轮前瞻（已知碰撞点）**：该行会把拉丁 / 西里尔 / 韩文与繁体汉字（cht「黃泉」）写进 **cn** 快照——cn 不在 `check-ai-endpoints.mjs` 的汉字残留扫描面内，故现状无风险；但一旦未来把条目级快照扩展到非缺省语言，`tools/ai-han-baseline.json` 的「非汉字脚本语言分层快照正文禁汉字」棘轮会把**合法的官方汉字译名**判成残留 ⇒ 届时必须同批裁决该行在分层快照里的取值语言范围（例：分层快照只出非汉字语言译名），否则棘轮必然红。
- **折叠规则是新增判据**：必须与页面同源实现，否则「与 H1 主名同字」的折叠在两端分叉，§3 逐字一致立刻破。
- **覆盖边界留空**：主名非令牌或全语言缺键的实体整行省略（与开拓者 `{NICKNAME}` 输出空串、前端不渲染的既有口径一致），**不为它们兜底命名**；因此「覆盖率」不是 100%，这是有意取舍而非缺陷。

### 被推翻时的回滚面

- **返回 / 回滚内容**：删除「多语言名称」事实行（生成器与前端页面两处）、LD 数组收回单值；若前置条件已引入「实体名 × 语言」产物，则连带删除该产物、其守卫与取数路径——这才是返工主体。
- **路由**：零返工。不新增可索引 URL，rewrite 表、`sitemap.xml`、1432 份快照数量均不变。
- **数据口径**：零返工。不新增字段、不改 `$t:` 令牌协议、不改语言包结构（[ADR 0052](0052-多语言站点架构-路径前缀与语言包.md) 决策 2 不动）。
- **跨模块契约**：**牵动**。① [ai-discoverability.md](../agents/ai-discoverability.md) §3 的事实行清单与「页面 ↔ 快照逐字一致」判据；② 若引入新产物，则牵动转换器与 `src/services/api/*` 取数层。
- **门槛自证**：返工不限于展示层 ⇒ 按 [conventions.md](../agents/conventions.md) 的可逆性判据，本决策够 ADR 门槛。
