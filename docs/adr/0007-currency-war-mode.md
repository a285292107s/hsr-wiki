# 货币战争升级为独立模式：交换导航 + 全壳暗金主题

货币战争是游戏中相对独立且重要的玩法板块，值得一级入口待遇。我们决定将其从"第 9 个导航栏目"升级为独立模式：导航首项由「首页」替换为「交换」按钮，点击后跳转至对方模式的枢纽页（`/` ↔ `/currency`）；CW 模式下导航栏其余项全部替换为 5 个子板块（角色图鉴、装备图鉴、投资环境、投资策略、羁绊图鉴），整个应用外壳（含侧边栏/底部导航）切换为黑底暗金主题。

## Considered Options

- **全局状态覆盖层（Pinia/localStorage 存模式）**：同一 URL 双模式渲染。放弃原因：URL 不可分享、刷新丢状态、每个页面背双模式复杂度。
- **`/cw/*` 新前缀**：命名空间更短。放弃原因：项目未上线但无谓制造迁移成本，`/currency` 前缀已足够清晰，语义升级即可。
- **仅内容区换肤**：导航保持紫调。放弃原因：导航项已换成 CW 板块，颜色割裂会破坏沉浸感；全壳覆盖在早期阶段零迁移成本。
- **全屏遮罩转场**：仪式感强但每次切换阻塞 600ms。放弃原因：高频操作不应被动画卡住；CSS 变量渐变（400ms）既有"世界换色"的叙事又不阻塞。

## Consequences

- 主题通过 `<html data-theme="cw">` + CSS 变量覆盖实现，SidebarNav 组件零改动、纯变量继承换肤。
- 路由 meta 标记 CW 归属，App.vue 据此切换 data-theme 与导航配置。
- 手机端 CW 模式底部栏为 6 槽位平铺（交换 + 5 板块），无"更多"抽屉；NavItem 接口新增 `short` 字段支持两级命名。
- 常规首页 `/` 保留，9 宫格中货币战争卡片升级为金色网关卡片（第二入口）。
- 暗金主题硬约束：导航小字（≤0.75rem）必须使用高亮度暖白文字，对比度 ≥4.5:1。
