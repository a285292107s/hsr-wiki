| F4 | **`SPNeed` 存在技能级版本** | 角色级 `SPNeed`（characters.json 的 sp_need）已输出；技能级 `SPNeed`（1,605 条，值 12-160）语义待确认（特殊资源角色如遐蝶【新蕊】？） |
| F5 | **基线对比** | StarRailRes `character_skills.json` 有 `element`/`max_level` 本地无输出；该仓库**没有** `CoolDown`/`SPBase`/`StanceDamageDisplay`（社区不认为它们是展示级字段，而我们已输出 `sp_base` 属超越基线） |
| F6 | **`ShowDamageList`/`ShowHealList` 全表 0 条非空** | 出现率 100% 但所有记录均为空列表 `[]`——纯占位字段，无任何信息量 |
| F7 | **`SimpleParamList` 与 `ParamList` 全表 0 条差异** | 6,804 条记录逐条对比完全一致——纯冗余副本，输出一个即可 |
| F8 | **`RatedSkillTreeID` 交叉验证成功** | 样例 `1002103` 在 AvatarSkillTreeConfig 中确认存在（角色 1002 的行迹点，AnchorType=Point08）→ 语义=「技能 → 行迹点」关联 |
| F9 | **`RatedRankID` 交叉验证成功** | 样例 `100206` 在 AvatarRankConfig 中确认存在（角色 1002 的第 6 星魂）→ 语义=「技能 → 星魂」关联，对应存疑表 #3「星魂改哪个技能」的反向链路 |
| F10 | **`SkillComboValueDelta` 为版本演进废弃字段** | 有值的 137 个技能全部属于 1.0-1.4 时代角色（1001 三月七 ~ 1304 镜流），**1305 及之后的新角色全部没有**——引擎模板遗留字段随版本废弃 |
| F11 | **技能级 `SPNeed` 与角色级部分不一致** | 100 角色对照：85 个一致；5 个精确 2 倍关系（1220/1221/1302/1415/1505，双段/增强能量机制）；10 个忆灵独有（11004-11310，角色级无忆灵能量数据）。**技能级携带角色级没有的信息 → 建议 🟡 可选而非排除** |
| F12 | **`SkillIcon`/`UltraSkillIcon` 无消费方** | 前端 `skillIconUrl()` 按类型键拼接 CDN 路径（`SkillIcon_{charId}_{Type}.webp`，format.test.ts 锁定），不读取源数据 SkillIcon 字段——未输出是有意设计 |
| F13 | **`LevelUpCostList` 全表空列表（实施阶段发现，2026-08-03）** | 试点按「出现率 100%」误判收录；实施时核实：**主表 6,804 条 + LD 293 条全部为 `[]`**——与 ShowDamageList 同类纯占位字段，无任何数据可输出 → **改判 🔴 排除**（闸门 1 类别① 值分布全空常量），用户 2026-08-03 确认 |
