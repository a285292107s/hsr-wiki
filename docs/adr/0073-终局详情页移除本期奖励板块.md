# 0073. 终局详情页移除「本期奖励」板块

**Status**: Accepted（已实现）

## 背景

[ADR 0062](0062-终局本期奖励上提为赛季级板块.md) 曾把逐层通关奖励与累计星数阶梯上提为四个终局玩法（忘却之庭 / 虚构叙事 / 末日幻影 / 异相仲裁）详情页底部的赛季级「本期奖励」板块，并做过一轮统一压缩。用户反馈该区块**对玩家价值很小，却占用太多空间**，要求从这 4 个详情页移除。

## 决策

- 移除 `EndgameView` 中的 `<EndgameSeasonRewards>` 挂载及其 import；详情页在关卡面板（`EndgameLevelPanel`）之后直接进入相邻赛季导航（`nk-egd-nav`）。
- 删除该板块专属的整条渲染链：`EndgameSeasonRewards` / `EndgameSeasonRewardGroup` / `EndgameReward` / `EndgameClearCondition` / `EndgameStarTierList` / `EndgameTargetRow` 六个组件，数据 shaping 模块 `season-rewards.ts`（`seasonRewardPlan` / `seasonRewardGroups` 及档位合并）及其单测。
- 清理 `renders.ts` 中仅供上述组件使用的导出（`rewardItemMap` / `ensureRewardItemMap` / `RewardItemMeta` / `StarTierRow` / `starTierRows` / `mergeStarTierRuns` / `TARGET_TYPE_LABEL` / `TARGET_TYPE_SVG` / `targetHtml` / `targetTypeIconHtml`），以及 `.nk-egd-season*` / `.nk-egd-tier*` / `.nk-egd-reward*` / `.nk-egd-node*` / `.nk-egd-rules*` / `.nk-egd-clear` / `.nk-egd-head__*` 等死样式与奖励专属词典键（13 语言 × 20 键）。
- 关卡 tab 内的挑战内容（增益、机制、敌方配置等）保持不变；数据产物字段（`floor_details[].reward`、`star_rewards` 等）保留，转换器零改动，前端不再消费。

## 替代方案（被否）

- **保留板块并默认折叠**：仍占首屏纵向预算；奖励属低价值信息，压缩后连可发现性也一并无益。
- **继续缩小密度 / 再压缩一轮**：ADR 0062 已做过统一压缩，边际空间收益有限，且用户判据是「价值小」而非「太长」。
- **仅隐藏不改代码**：留下死组件与死样式，构成后续漂移与误用风险，故整链删除。

## 后果

- 取代 [ADR 0062](0062-终局本期奖励上提为赛季级板块.md)；[ADR 0051](0051-终局赛季奖励进详情页.md) 的「奖励展示」部分自此彻底退场（数据产物与转换器保留）。
- 四个终局详情页在关卡面板之后直接进入相邻赛季导航，首屏不再被奖励板块挤压。
- `season_rewards` / `floor_details[].reward` 等字段仍在数据层（供未来复用），当前无前端消费方。
