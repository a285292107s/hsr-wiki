# 0028. 终局详情页父子层级刻度

## 状态

`accepted`（**已实现**：`endgame-detail.css` 新增 `.nk-egd-children` 单点声明——`--eg-indent`（16px，<768px 12px）+ 左侧 3px 圆角渐隐竖轨；`EndgameTierce` / `EndgameFloors` / `EndgamePeak` 三处子块挂类；星启节点行中文主字升到父档、`NODE-0N` 降为次级 HUD 标签；楼层「阶段/半场」胶囊提到子档 0.72rem。**星启部分的档位映射与几何挂点被 [ADR 0032](0032-星启节点按完整场次渲染.md) 修订**：星启节点改扁平场次卡后，父行主字承载**场次文案**（`NODE-0N` 编号退场）、子档几何挂在 `.nk-egd-tierce__nodebody`、星启「波次」按 DOM 深度落到孙档。**星启看板体不再画这条竖轨（缩进保留）**——轨宽提为消费侧开关 `--eg-rail-w`，由 [ADR 0033](0033-星启模式改单节点看板.md) 决策 13 覆写为 `0`；楼层折叠体与异相仲裁不变）

## 背景

终局详情页一页之内有四种模式、三种 DOM 形态，父子层级靠各写各的字号表达，结果星启模式那处塌了：

- **字号代差不足**：星启节点行 `0.74rem`（HUD/700）× 波次行 `0.72rem`（正文/600），代差只有 0.02rem ≈ 0.32px；而同一页的楼层头是 `1.08rem`/800 亮色、子级是 `0.66rem` 胶囊——星启这处明显偏离页面内已成立的梯度。
- **左缘齐平**：节点行左内距 `0`、子块左内距 `2px`，父子只差 2px，视觉上读成两组并列文本，没有嵌套感。
- **移动端倒挂**：<768px 节点名 `0.7rem` < 波次名 `0.72rem`，子行字比父行大。
- **同页已有层级语言却未被复用**：绝境变体 `.nk-egd-floor__hard` 早就用「`padding-left: 16px` + 左侧 3px 圆角渐隐竖轨」表达子级；技能页也用「缩进 + 竖轨层级线」（[ADR 0022](0022-技能层级以行迹族为唯一来源.md)）。星启是漏网的一处。
- **打破它的代价已被登记**：反 AI 味硬约束要求「发丝线取代虚线」，虚线只在技能页有豁免；本决策用实心竖轨，不新增豁免。

三种形态的层级数并不相同，这是「按什么定档」成为关键决策的原因：楼层是「层 → 阶段/半场 → 波标签」，异相仲裁是「关卡 → 字段行/波标签 → 敌卡」，星启是「节点 → 波次 → 敌卡」（星启节点 1/2 就是常规最高难度关的上下半场，见 [CONTEXT.md](../../CONTEXT.md) 星启模式条，故它的「波次」在语义上比楼层的「波次标签」高一层）。

## 决策

**我们把「层级刻度」作为终局详情页的原生视觉契约，档位按 DOM 嵌套深度落位**：

1. **档位表**：父档 = 层 / 关卡 / 节点（字号 `1.0–1.08rem`、`weight 800`、`--text-bright`，无缩进）；子档 = 紧贴父级的子块（缩进 `16px`，<768px `12px`，左侧 3px 圆角渐隐竖轨，行头 `0.72rem`/600/`--text2`）；孙档 = 再下一层的小标签（「第 N 波」`0.66rem`/`--text3` + 6px 圆点）。**同一元素换一层嵌套就拿另一档**——星启的「波次」是子档，楼层与异相仲裁的「波次标签」是孙档。（**被 [ADR 0032](0032-星启节点按完整场次渲染.md) 修订**：星启节点改为「场次父行 + 内容子块」后，星启「波次」由子档落到孙档，与楼层一致；父档仍按 DOM 深度落位，只是星启父行的文案换成场次。）
2. **几何单点声明**：`.nk-egd-children` 是缩进与竖轨的唯一声明处（`--eg-indent` 断点令牌 + `::before` 竖轨），三组件挂类复用——星启挂在节点体（**ADR 0032 后为 `.nk-egd-tierce__nodebody`**，原 `__nodebody-inner`）、楼层挂在整个折叠体（`.nk-egd-floor__body-inner`，而非只挂阶段容器）、异相仲裁为卡体新增包裹层 `.nk-egd-peak__body`。绝境变体改为消费同一几何，只把轨道色覆写为 `--diff-del`——危险语义色不因统一而被降级成纯层级色。（**轨宽另提为 `--eg-rail-w` 开关（缺省 3px），星启看板体覆写为 0 = 该处不画轨，见 [ADR 0033](0033-星启模式改单节点看板.md) 决策 13**：声明仍单点，开关按消费侧生效。）
3. **父行身份**：星启节点行中文「节点 N」升为父行主字（`1rem`/800/`--text-bright`），`NODE-0N` 降为次级 HUD 标签（`0.6rem`、`--eg-color` 66% 混 `--text3`），与楼层头「第 N 层」以及目录页 `nk-eg-col__name` + `__en` 的「中文主 / 英文次」范式一致。（**被 [ADR 0032](0032-星启节点按完整场次渲染.md) 修订**：父行主字保留同档样式，文案改为场次（上半场/下半场/星启附加关），`NODE-0N` 与「节点 N」编号一并退场。）
4. **子档口径统一**：楼层「阶段/半场」胶囊由 `0.66rem` 提到 `0.72rem`，与星启波次行头同档；孙档「第 N 波」维持 `0.66rem`（<768px 保留 `0.7rem` 可读性下限）。
5. **收折态同读**：收折的父行与收折的子级同为 5% 模式色底纹（改前只有子级有底纹，父级收折只能靠箭头读出）。

## 后果

**正面**

- 四种模式共用一套可以陈述、可以断言的层级刻度，新增形态有档可对，不必再逐处调字号。
- 页面内既有的绝境变体几何上收为共享原语，子级表达不再各写一份。
- 星启的「节点」文案与 [CONTEXT.md](../../CONTEXT.md) 的写法（节点 1/2/3）对齐，`NODE-0N` 编码退居次标。（**ADR 0032 后不再上屏**：节点改成扁平场次卡，标题走场次口径。）

**负面**

- 楼层「阶段/半场」胶囊变大 0.06rem（`0.66 → 0.72rem`）——统一档位的代价是**未报问题的区域也被改动**。
- 异相仲裁卡体为挂类新增一层包裹元素；绝境块的竖轨从卡体左缘（`x = 0`）移到子块内容区（`x = 16px`），其内容总缩进由 16px 变 32px（嵌套深度增加一层的直接结果）。
- 绝境变体的竖轨几何被共享规则接管，渐隐从「100%→50% × 0.75 不透明度」变为「72%→34%」，观感略有变化。
- 星启节点行升档后行高变大，节点多的赛季纵向更长。
- 三档刻度是**约定**而非强制：新增子块挂错档位不会被守卫或类型系统拦住，只有 `e2e/layout.spec.ts` 的断言覆盖现有三处。

**中性**

- 不涉及数据与文案来源，AI 快照不含节点/波次标签（`tools/gen-ai-endpoints.mjs` 只输出一行「星启模式：关卡…」），无需同步；像素基线只覆盖 `/endgame` 目录页，不经此改动。
- 「多波才显示波标签」的既有信息取舍不变；箭头尺寸（父级 16/13px、子级 14px）维持现状。
- 收折态一致性只落到星启两级折叠树：楼层折叠态由摘要行（`.nk-egd-floor__summary`）承担可见性，不另加底纹。

## 替代方案

| 方案 | 为何未采用 |
|---|---|
| 只靠字号/字重代差，不加缩进与轨线 | 父子左缘仍只差 2px，窄断点下仍读成两组并列文本 |
| 只加缩进与轨线，不动字号 | 用户报的「字体差异小」本身未被处理 |
| 父行改承载面（底纹条 + 发丝下边线），子行保持裸文本 | 与页面「靠发丝线分区、不用卡片面」的语言相抵，多一层卡片感 |
| 按语义身份定档（阶段/半场恒为子档、波次恒为孙档） | 星启缺中间层，父档会直接跳到孙档形成断层；且同一元素在不同模式下档位不同，反而更难推理（**ADR 0032 后星启有了中间层**——场次卡行头即子档，故星启「波次」按 DOM 深度自然落到孙档，档位仍按深度而非语义身份） |
| 不建档位表，只保证相邻两级有明确代差 | 四种形态之间的绝对读数不统一，日后新形态无档可对 |
| 手机端单独一套（只缩进不画轨 / 沿用现状） | 全断点读数分叉；且手机端的字号倒挂（子行大于父行）会保留 |
| 只修星启一处，另三种形态留待后续 | 用户明确选择四模式统一；且档位若不定，星启升到哪一档同样无据 |
