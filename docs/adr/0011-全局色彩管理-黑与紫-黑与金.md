# 全局色彩管理：常规黑与紫 · 货币战争黑与金

## Status: accepted

## Context

全站色彩此前是"蓝紫调假黑 + 交叉金色"：常规模式背景 `#0F0F23`（偏蓝，非纯黑），表面色散落手写 `rgba(15,15,35,…)` 系列；主色 Purple Heart 500 之外还有游离玫红 `--accent #F43F5E` 与金色家族（星级/属性/强化角标/文本高亮）混居；CW 模式黑底金主色已成立，但底色同为散落 rgba。`check-colors --strict` 虽全绿，却豁免"深底色"——散落事实正藏身于此，无法被审计。目标：全局色彩管理，双模式收敛为双色表达，黑成为单一事实来源。

## Decision

1. **中性黑阶 + 主色注入**：新增 `--blk-*` 原始层（纯中性黑阶，无色相，深色端 4 级：950 纯黑 / 900 / 850 / 800 渐亮）。所有深色表面（`--bg` / `--surface` / `--card` / 壳 / 抽屉 / 头部 / 输入框）从手写 rgba 改为黑阶派生；主题色相通过 `color-mix` 混入主色（约 3~8%）注入，黑阶本身不写色相。`--bg` 取最黑一级（纯黑或极淡染色），表面逐级提亮。
2. **双色约束**：常规模式 = 黑与紫、CW = 黑与金；主题内所有强调色必须落入该模式的**主色族**，禁止第三色相。`--primary` 保持 `ph-500`（常规）/ 换为 `gold-500` 金属金（CW，原 `gold-300`）；文字/细线强调位走族内亮端（常规 `--metric-val` = `ph-300`，CW = `gold-300`），大面积标识用族内基准位。"发光位唯一"恒等式由"文字位亮金 + 主色位金属金"重组维持。
3. **`--accent` 收编为主色梯度端**：常规 `#F43F5E` 玫红 → `ph-400`；CW `#C98A2D` → `gold-600`。`--accent` 变量保留（引用面约 17 处不动），语义从"游离色"改为"主色的渐变端点"；Hero 区段竖条、mob 卡、CW 装饰条渐变保持同族渐变。
4. **领域色豁免**：星级/属性数值/元素/强化角标/文本高亮在常规模式保持金色——"黑与紫"只约束主题层（背景/表面/强调），数据语义色不随主题（CW 内领域金维持暗铜降阶）。双色约束与领域豁免的边界是本次重构的核心边界，常规 = 黑底 + 紫强调 + 金仅存数据语义位，与 CW 形成同构镜像。
5. **门禁升级**：`tools/check-colors.mjs` 的"深底色豁免"收窄为仅放行 `--blk-*` 派生（含 color-mix 引用），页面散落 rgba 收编入令牌后方可通过 `--strict` 验收。

## Considered Options

- **双黑族（冷黑/暖黑独立）**：黑里自带主题氛围（常规微冷黑、CW 微暖黑），但黑失去单一事实来源，两套黑阶分别维护。被拒——与"三层令牌唯一来源"原则冲突，且双色纯度由两套黑各自决定、无法统一参数化。
- **领域金改紫/降阶**：常规模式 100% 双色，但 5 星变紫违背游戏内约定（玩家认知锚点），且与 CW 的"语义金降阶保留金色"处理不对称。被拒——领域层不随主题是既有架构原则。
- **CW 主色保持 `gold-300`**：白金在纯黑底上偏轻飘泛黄；`gold-500` 金属金质感最正。换阶后文字强调位由 `gold-300` 承接，明度损失不触及阅读位。
- **仅 tokens 重构（不动页面）**：工作量小，但"黑"会被页面散落的蓝紫 rgba 稀释，双色不纯。被拒——收编页面层才是本次重构的价值主体。

## Consequences

- 实施分三阶段：① tokens.css 新增黑阶 + 双主题语义层重映射；② 页面 CSS 散落 rgba（Hero 边缘内阴影、skeleton、mob 卡、shell 变体、占位页等）收编；③ 门禁升级 + `pnpm build` + `pnpm test` 全绿 + 双主题视觉回归截图。
- 常规模式视觉将明显变暗（背景从 `#0F0F23` 蓝紫调 → 纯黑），依赖旧 rgba 的层次（Hero 边缘柔化、骨架屏、错误态）需同步校准。
- 对比度校准点：黑化后 tab 激活文字、章节编号等直用 `--primary` 的文字位改走亮端（`--metric-val` 或 color-mix 提亮）；`--primary` 本身不动。
- `--hero-bg-deep` / `--hero-bg-tint`（Spine 失败兜底渐变）收编为黑阶 + 主色注入，保持"深紫兜底"视觉意图。
- CW 主色从 `gold-300` 换 `gold-500` 后，现有引用 `--primary` 的发光/激活态自动跟随，需视觉回归确认明度变化可接受；`--swap` 交换按钮的双色状态点（紫=常规、金=CW）语义不变。
