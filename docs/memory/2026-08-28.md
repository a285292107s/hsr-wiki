## 资源本地化第一批：公共小图标 / spine-player 运行时 / CW Hero 视频（local-first）

- 触发：08-28 会话完成「哪些资源适合本地化」分析（资源盘点 + 适配性分级），用户裁定按建议执行。背景挂账：08-11/13 jsDelivr 大陆直连慢 + burst 限流 → 图片密集页破图。
- **改动**：
  - spine-player 4.2.43 / 4.1.23（npm dist 原样，602KB + 496KB）入库 `public/vendor/spine/`，`SPINE_RUNTIME_LOCAL` 本地主源，`SPINE_RUNTIME_CDNS` / `SPINE_RUNTIME_41_CDNS` 降级为兜底；本地源不受 `isCdnDown()` 短路影响（CDN down 时动画仍可用，runtime.test 语义已改写）。
  - CW Hero 视频（5.2MB）入库 `public/data/cn/assets/cw-hero.mp4`，`CW_HERO_VIDEO` 改本地；poster 兜底链不变。动因：act-webstatic 活动素材无保留 SLA（同 ADR 0009 官网 Spine 结论）。
  - 公共小图标 38 张（215KB webp）入库 `public/data/cn/assets/icons/{element,pathicon,trace,relicfigures}/`；`services/cdn/base.ts` 新增 `local` / `localFiles` 注册字段 + `LOCAL_ICONS_BASE`，`resolveCdnUri` 三级解析（本地 → jsDelivr → nanoka）；dom 委托对本地主源失败现场反查远端最优源（`localFallbackFromPrimary`，不依赖 data-cdn-fallback 属性，模板零改动）。`icons.ts` 的 elementIconUrl / pathIconUrl 收口回 cdnUri（原官方模式直拼 jsDelivr 绕过 resolve 层）。
- **坑位（必知）**：nanoka `assets/hsr/trace/*.webp` 全部是 146 字节占位图（RIFF/WEBP 头合法但非真图标）——trace 的真源只有 jsDelivr（`spriteoutput/ui/avatar/icon/Icon{key}.png`）。trace 本地图标由 jsDelivr PNG 经 Pillow 无损转 webp 入库；本地缺失时回退必须走 jsDelivr（`resolveCdnUri` 的 fallback 取远端最优源，非一律 nanoka）。
- **验证**：cdn.test.ts 34 例 + runtime.test.ts 9 例改写/新增；`pnpm build` + `pnpm test`（261 例）全绿；dist 产物含全部新资产。
- **遗留（专项决策，未做）**：③ 官网 Spine 源 15 角色归档（~120-230MB 入库，抢救性质——官网过期即抓不到）；⑤ 目录页高频卡片图子集本地化（对症 jsDelivr 破图挂账，需带宽预算 + converter 增量图片下载管线）。08-13 生产可用性挂账仍开放，⑤ 是候选解之一。
