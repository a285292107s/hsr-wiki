> 决策正文见同目录各文件。ADR 门槛：仅「不可逆 / 跨模块架构决策」入库（见 [../agents/conventions.md](../agents/conventions.md)）。
> **必填四件套**：背景 / 决策 / **替代方案与原因**（否决项，防 AI 重走老路）/ 后果——章节名自由，实质内容必须在场；行文隐含旧方案与理由的视为合规（见 conventions.md「ADR 必填字段」）。**机械判据**：`node tools/doc-audit.mjs` 检查「替代方案 / 否决」是否有**结构化落点**（`## 替代方案（被否）` 一类标题，或 `**Considered Options**` 一类加粗字段）；只有行文暗示而无结构化字段时报「疑似缺失待复核」。编号 0001（宿主隐藏与分段降级）在「寄生油猴 → 独立站」同一提交中被 0004 承接并删除，不保留占位行；编号 0017 曾用于「导航枢纽项指向图签页」并已作废删除，**明文不复用**，故同样不保留占位行。
