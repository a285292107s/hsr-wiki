# 异相仲裁赛季页并入关卡子 tab 编排

**Status**: Accepted（已实现）

## Context

四个终局玩法的赛季页此前挂着两套编排：忘却之庭 / 虚构叙事 / 末日幻影走「第 1..N 层 / 星启模式」子 tab + 单场看板（[ADR 0037](0037-忘却之庭虚构叙事详情页并入层级子tab编排.md)），**异相仲裁仍是纵排区块 + 顶部固定条**——4 关串成一个长块（实测 `/endgame/peak/9` 面板 3278px、固定条 47px），关卡身份落在卡体 h3 上；面板内 `.nk-egd-floor__head` 还带着 `cursor: pointer` + `:hover` 底纹（该元素从不是按钮，是从折叠楼层时代遗留的**假交互**）。

数据事实（实测）：

- 10 期异相仲裁 `levels` 恒为 4 关，官方关卡名恒为 骑士（一）/（二）/（三）+ 将杀王棋，`id` 按期递增（101–104 … 1001–1004）；
- 四份产物 116 期**没有一期**的 `floor_details` / `tierce` / `levels` 全空 ⇒ 顶部固定条在数据层面已无消费方；
- 每期的赛季级 `buffs` 与王棋关 `levels[].buffs` 是**同一批 3 条 ID**（10/10 期逐 ID 相同）⇒ 赛季级增益区块对异相仲裁本就是重复陈述。

## Decision

1. **`buildLevelTabs` 覆盖异相仲裁**（`levels.ts`）：`levels` 非空时按源序造 tab（`key = peak-<关卡 ID>`、label = 官方关卡名），否则退回原来的「层 + 星启」；新增 `peakKey` / `levelTabPeak` 解析。`isLevelMode` **删除**——四模式同构后判据塌缩为 `buildLevelTabs(data).length`，「谁是层级模式」不再是一个需要维护的白名单。
2. **面板一次只渲染一关**：`EndgamePeak` 收窄为单关面板（props 由 `data + peakLevels` 变为 `level`），`EndgameLevelPanel` 增 peak 分支。4 关不再同屏。
3. **身份只在拥有它的那一档出现一次**（沿用 [ADR 0033](0033-星启模式改单节点看板.md) 决策 11）：关卡名由激活 tab 承担，面板头只留类别胶囊（骑士 / 王棋）+ 污染等级徽标 + 敌方等级（tab 上读不到的字段）；h3 与 `.nk-egd-floor__title` 一并退场。
4. **顶部固定条与避让内距整条退场**（修订 ADR 0037 决策 1）：`.nk-egd-bar` / `.nk-egd-bar__progress` / `.nk-egd-secnav` / `#egd-levels` 的 `scroll-margin` / `[data-mode="peak"] { padding-top: 46px }` 全部删除，`.nk-egd.nk-page--detail { padding-top: 0 }` 成为四模式统一值；滚动定位只保留「返回顶部」圆钮。
5. **段位徽章升为赛季级区块**：新增 `EndgameBadges.vue` + 锚点 `#egd-badges` + `.nk-egd-badges*`（标题取 [CONTEXT.md](../../CONTEXT.md) 登记词「段位徽章」），排在污染等级之后。徽章是赛季成就而非某一关的属性，此前埋在「关卡组成」区块里、随 4 关同屏。
6. **赛季增益的退场改用数据判据（零 `modeKey` 分支）**：`seasonBuffList` 的「已承担」集合从 `floor_details[].buff` / `tierce.nodes[].buff` 扩到 `levels[].buffs`——赛季 `buffs` 与王棋关增益同一批 ID 时整块自动退场，有差额时只留差额。
7. **删死形态**：`.nk-egd-floors`（唯一消费方是旧的 4 关纵排）、`.nk-egd-floor__head` 的 `cursor` / `::before` / `:hover`（假交互）、`#egd-levels` 锚点与区块清单里的 `levels` 项。

## Alternatives considered

- **保留固定条，只把 4 关塞进 tab**：[ADR 0030](0030-末日幻影详情页层级星启子tab.md) / 0037 已两轮判定「页内一行 tab 放进常驻横条 = 凭空造一条横条」，且要付 `padding-top`、`scroll-margin`、撑高固定条三处几何代价。
- **单关面板并入 `EndgameBoard`**（真正的「同一套看板」）：看板块序（末法余烬 → 首领特性 → 敌方配置 → 赛季增益）与单关内容不同——异相仲裁没有「末法余烬」与「首领特性」两块，赛季增益也不在面板尾而是在挑战目标之后。**（2026-10-05 补记：其中「推荐属性 + 敌方配置」两块已并入共享件 `StageContent`——见下方「补记」节，单关敌方改走敌方详情卡；`EndgameBoard` 本身仍未并入。）**
- **4 关做成卡片行（`EndgameNodeCards`）而不是 tab**：卡片行的语义是「同一关内的场次」（上下半场 / 星启节点），4 个关卡是同级并列的关卡，属 tab 档。
- **保留固定条只作滚动进度指示**：四模式只给一个模式留常驻 chrome，等于把刚统一掉的分叉再造一次。

## 补记（2026-10-05：单关敌方并入 `StageContent`，敌方详情卡）

设计稿落地后用户点名「异相仲裁详情页面的怪物卡片，也参考末日幻影中的怪物」，量出两处真实差距并一并收口：

1. **渲染形态**：单关的敌方原为 `EndgamePeak` 内联的**圆形小图标格**（46px + 召唤物），末日幻影层看板早已是**敌方详情卡**（立绘 104px + 名称 + 阵营/韧性/速度 + 弱点/抗性 + 图鉴介绍 + 技能 + 召唤物）。现将推荐属性与敌方配置整块改由共享件 `StageContent` 渲染（新增 `damage` / `showCount` 两个**可选**入参，只有没有卡片行的异相仲裁传），单关与其「绝境」变体都走同一件——旧图标格 6 条样式（`.nk-egd-floor__mons` / `__moncell` / `__monlink` / `__mon` 及其断点覆写）整批删除，`EndgamePeak` 少 2 个内联区块。
2. **数据形态**：末日幻影楼层的敌方是 `full=True` 全字段，异相仲裁单关原为轻量字段 → 卡片上的图鉴介绍与技能整块空缺（实测 peak 28 条敌方 0 条带 `intro`/`skills`）。转换器 `_peak_level_node` / `_peak_seasons` 增 `full_monsters` 开关并在 `build()` 传 `True`；期级合并列表改用 `_lean_monster` 去 `wave`/`intro`/`skills`，保持与另外三种模式的期级列表同口径（它只服务目录卡代表阵容与 AI 快照）。**代价**：`maze_peak.json` 131 KB → 234 KB（+103 KB，10 期；对比末日幻影同口径 560 KB / 22 期），其余三份产物逐字节未变。
3. **触摸端的连带修正**：`intro` 的展开途径只有 `:hover`（桌面 3 行截断 → 悬停展开），触摸端没有 hover ⇒ 图鉴介绍永久读不全。`@media (hover: none)` 下整段放开（实测 412px：clamp `3` → `none`，介绍 55px → 239px）。**代价**：触摸端卡片变高（首卡 360 → 624px），换取内容不丢。

**中性条**：`.nk-egd-floor__moncount`（「N 波 · M 敌」）仍只由异相仲裁保留——末日幻影/星启看板的该统计随看板行头退场（ADR 0033 决策 11）。

## Consequences

- **好处**：同模式合集的四个赛季页骨架一致（Hero → 赛季级区块 → 关卡子 tab → 单面板）；异相仲裁赛季页高度由 3278px 降到单关量级（骑士关 ≈570px、王棋关 ≈1100px）；段位徽章有了语义正确的归属；假交互与死形态清零。
- **负面清单**：
  1. 一次只看一关 ⇒ 同期比较四关要多点 3 次；tab 即源序（一/二/三 → 王棋），不提供「全部展开」；
  2. 关卡名只在 tab 上：窄屏（≤412px）由 `.nk-egd-tabs` 的 `flex-wrap` 兜底，极端长名会折行（实测 375px 仍单行）；
  3. 竖轨保留（[ADR 0028](0028-终局详情页父子层级刻度.md) 决策 2 与 ADR 0033 决策 13 的中性条不变）：异相仲裁是四模式里唯一没有卡片行的，单关面板体是子档的唯一承载者；
  4. tab key 用关卡 ID（101–104 … 1001–1004），跨期不连续 ⇒ 切赛季必然重算激活项（`watch(levelTabs)` 已覆盖）；
  5. 关卡面板头不再出现关卡名：从外部深链/截图单看一张面板时，身份只能靠上方 tab 行读出（与忘却之庭「第 N 层」同判据，见决策 3）。
