# 0072. 全站导航统一为持久顶栏

**Status**: Accepted

## 背景

此前桌面与平板用左侧栏，手机用底部 Dock。底栏按纯视口函数选可见前缀，不能保证当前章节留在导航条内。统一顶栏同时改变应用外壳、页内贴顶控件的避让基准与导航契约。

## 决策

- 全站以 [UI 设计 §6](../agents/ui-design.md) 的持久顶栏替代侧栏和底部 Dock；按实际宽度判断行内或紧凑态，紧凑态优先保留当前章节，而不是保留固定前缀。
- 不改变路由、枢纽页内容或「交换」落点；跨模式仍只走「交换」，落点沿用 [ADR 0016](0016-枢纽页模式切换入口的落点分工.md) 决策 1。

## 替代方案

- 保留侧栏和底部 Dock：维持两套外壳及避让规则，不符合全站统一顶栏的要求。
- 按固定断点或等分槽位折叠：不能覆盖同宽度下不同译文与工具区占位；按顺序保留固定前缀也不能保证当前章节可见。

## 后果

- 顶栏成为页面纵向避让基准；页内贴顶工具栏与滚动定位不能再把视口顶部当作内容区顶部。旧左侧和底部避让退场。
- 同一视口宽度允许因译文或工具区宽度而切换形态；紧凑态进入其余章节多一步。验收关注各章节可达与工具位常驻，不把某语言的折叠宽度写成契约。
- 取代 [ADR 0054](0054-底栏槽位数与语言解耦.md)；修订 [ADR 0003](0003-self-built-sidebar.md)、[ADR 0015](0015-研究线迁入主站dev路由.md) 和 [ADR 0019](0019-枢纽页导航条回归与首页改为版本上新页.md) 的外壳形态，保留导航自持、调试入口的显示范围以及枢纽全断点导航。
