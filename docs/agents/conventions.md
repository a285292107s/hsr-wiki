# 项目约定 — 代码规范 / 注释规范 / 决策落位

> AGENTS.md 的按主题子文件（主文件「任务 → 必读」路由表经相对链接引用）。存放跨文件、跨会话的写码与流程约定。**硬约束（MUST）与色彩令牌收口在主文件「强制规则」节**；UI / 样式约定见 [ui-design.md](ui-design.md)；验证职责边界见 [verification.md](verification.md)。

## 代码约定

- Vue SFC 统一使用 `<script setup lang="ts">`。
- 路由使用 `createWebHistory`（History 模式）——Vercel 支持 SPA fallback；Vite `base` 为 `/`（部署于域名根路径）。
- **样式相关的全部约定**（BEM 双前缀 `nk-` / `ui-`、样式分层与懒加载、`tokens.css` 令牌、不使用 CSS 预处理器）**收口于 [ui-design.md](ui-design.md) §1**——本文件不复述，避免双事实源漂移。
- 项目**不配置 ESLint / Prettier**：代码风格靠 vue-tsc 类型检查 + 本文件与主文件约定 + 代码审查保证，**禁止擅自引入 lint 工具链**。

## 注释规范

**注释可删性判据（唯一判据）**：只允许写「代码与数据都推不出、且 `docs/adr/` 或 `docs/` 里也不存在」的事实。凡读代码即可推理的内容——实现步骤、结构层级、命名已表达的意图、样式数值、类名与选择器的对应关系——**一律不得写成注释**。判不准时自问「删掉后，后续 AI 会不会据此改错代码」：会则留，不会则删。

- **允许保留**：外部资产的客观状态（上游 404 / 占位贴图 / 需回退某源）、字段来源与映射规则、上游数据特殊形态（旧 id 形式、哨兵值语义）、异步时序陷阱、运行环境特例、工具指令注释（`# noqa` / `# type: ignore` / `@ts-expect-error` / `@__PURE__` 等——这是指令，不是文档，**不得删除**）。
- **必须删除**：复述实现、设计意图与审美理由、历史沿革、纯分区横幅、跨文件重复的 SSOT 指针句，以及「禁止…/必须…」类约束——后者只要已被 ADR 或 `docs/` 承载，代码处即**不得重复**。
- **可能频繁改动的内容不得写注释**（样式数值尤其如此）：过期注释会主动误导后续 AI，其害大于利。

**落位分层**：术语进 `CONTEXT.md`；不可逆决策进 `docs/adr/`；踩坑与历史进 `docs/memory/`；其余一律不进注释。**禁止**以「注释第一读者是 AI」为由在代码里复述上述文档已承载的信息。

**换行符**：全仓文本文件行尾为 LF（`.gitattributes` 的 `* text=auto eol=lf` 锁定）。历史上双 CR（`\r\r\n`）曾在 35 个文件上累积并导致整文件 diff，**禁止**引入任何 LF→CRLF 的批量转换。

## 决策落位（ADR 门槛）

ADR **仅用于「不可逆 / 跨模块架构决策」**——不符合该门槛的决策（单文件配置、数值调整、流程细节）写入 `docs/memory/` 复盘日志或 commit message 正文，**不新增 ADR**。

## commit message

使用 Conventional Commits 风格（`feat:` / `fix:` / `chore:` 等，与 data-sync 自动化提交一致）；流程细节类决策写入 message 正文。

## 字段筛选

字段筛选遵循 `docs/audit/字段价值审计流程.md`：AI 生成解读卡（字段名 → 人话语义 → 证据 → 置信度 → 价值建议），人工裁决分档。该流程为**三道防错闸门**，判据与分级符号以该文件为准，本文件不复述：

- 闸门 1（单向门）：AI 无权判「排除」档，只能建议「必收」与「待定」。
- 闸门 2（字段基线兜底）：StarRailRes / 官方 wiki 基线有而本地无的字段必须标「待定」。
- 闸门 3（误杀率校准）：误杀率超阈值即收紧 AI 排除权限。
