# 0037. 忘却之庭 / 虚构叙事详情页并入层级子 tab 编排

## 状态

`accepted`（**已实现**：`buildBossLevelTabs` / `bossLevelFloor` / `BossLevelTab` 泛化为 `buildLevelTabs` / `levelTabFloor` / `LevelTab` + 新的 `isLevelMode`，三种层级模式共用同一套子 tab 构造；`EndgameBossFloor.vue` 改名 `EndgameFloor.vue` 并承接忘却之庭 / 虚构叙事（新增半场卡片的「回合」行与面板右栏「赛季规则」）；`EndgameNodeCards` 的 `items` 增加可选 `countdown`；`EndgameStarTargets` 的栏名按目标类型派生（全 `TOTAL_SCORE` → 星级目标，否则挑战目标）；`sections.ts` 的层级模式只产出赛季级区块并新增 `seasonBuffList()` 去重判据；`EndgameView` 的非层级分支缩到只剩异相仲裁；`endgame-detail.css` 的 `padding-top` 由 `data-mode="boss"` 归零改为**只有 `peak` 保留** 46px 固定条，并删除折叠楼层相关的死选择器；同批删除 `EndgameFloors.vue` / `EndgameTargets.vue` / `StageHead.vue` 与 `renders.endgameGroups` 等死形态。**修订 [ADR 0030](0030-末日幻影详情页层级星启子tab.md) 决策 1 的「固定条只服务另外三种模式」、决策 2 / 3 的「boss 独占子 tab」、[ADR 0035](0035-末日幻影层tab改半场卡片与单看板.md) 决策 1 / 2 的层 tab 归属与卡面项、中性条「`EndgameTargets` / `StageHead` 保留」、[ADR 0028](0028-终局详情页父子层级刻度.md) 决策 2 的三处几何挂点**）

> **被 [ADR 0031](0031-末日幻影层级敌方取实际战斗数据.md) 修订**：层级模式的敌方配置改取「实际战斗数据」而非 `phases` 渲染（本 ADR 的背景 1 与决策 1 里依赖旧 `EndgameFloors` 分支的表述随之作废）。

## 背景

1. 用户原话：「参考末日幻影详情页面的排版，重构忘却之庭和虚构叙事详情页面排版。」——基准页在 ADR 0030 / 0033 / 0035 三轮之后已经是「第 1..N 层 / 星启模式」子 tab + 单场看板的形态，而忘却之庭 / 虚构叙事仍是改造前的纵排区块（战意机制 / 赛季增益 / 污染等级 / 星启模式 / 关卡折叠楼层）+ 顶部固定条。**同一玩法合集的三个页面挂着两套编排**，读者在两页之间来回换读法。
2. 数据侧没有阻力：maze 57 季 / story 27 季**全部**带 `floor_details`，其中 4 + 4 季另有 `tierce`；层结构与末日幻影逐字同构（`stage1` / `stage2` + 层记录 `level` / `countdown` / `buff` / `targets`）。前端零转换器改动即可接通。
3. 三条真实差异决定了哪些内容不能照抄基准页：赛季增益的**承担位置**、层级目标的**类型**、回合上限 / 通关分数线的**层级归属**。它们各有数据判据，不靠 `modeKey` 硬分支。

## 决策

1. **子 tab 覆盖三种层级模式（用户裁决 Q1）**：`isLevelMode('maze' | 'story' | 'boss')` 为真时 `EndgameView` 走子 tab 分支，`peak`（异相仲裁，无层级）仍走纵排区块 + 顶部固定条。顶部固定条因此**只剩异相仲裁一种场景**，`padding-top` 的例外从 `[data-mode="boss"]` 改为 `[data-mode="peak"]`——判据从「谁是特例」翻成「谁还需要条」，新增层级模式不会再漏掉归零。

2. **关卡层级与星启模式一律由子 tab 承载**：层级模式不再渲染 `#egd-floors` / `#egd-tierce` 锚点，`buildEndgameSections` 对三种模式只产出赛季级区块（战意机制 / 赛季增益 / 污染等级）。`EndgameTierce` 的非嵌入形态（自带区块标题）随之失去唯一消费方，`modeKey` / `embedded` 两个 prop 与 `sectionIdx` 计算同批删除——**星启在三模式里都只是 tab，不是页面级区块**。

3. **「同文则不重复」判据落在 `renders.seasonBuffList()`（用户裁决 Q2）**：赛季增益与每层层内增益是同一条时（忘却之庭的「记忆紊流」：`buffs[0].id === floor_details[*].buff.id`，57 季实测 55 季逐条相等），赛季级「赛季增益」区块整块退场——层看板的层级增益位已经逐层呈现。虚构叙事的三条赛季机制（触技 / 笑韵 / 变奏 …）没有逐层对应，区块保留。**判据用增益 ID 而不是文案比对**：同 ID 即同一条上游记录，文案必然同文；反过来逐字比对文案会在上游改写描述时误判成「两条」。星启节点自带的 `buff` 同样计入「已承担」集合。

4. **层级目标的栏名按目标类型派生（不新增第四种叫法）**：`EndgameStarTargets` 原先把栏名写死成「星级目标」（ADR 0033 / 0035 为基准页定的口径）。忘却之庭的层目标全是 `ROUNDS_LEFT` / `DEAD_AVATAR`（游戏内叫「挑战目标」），照抄会张冠李戴。故改为：**全部为 `TOTAL_SCORE` → 星级目标**（虚构叙事 / 末日幻影），**否则 → 挑战目标**（忘却之庭）。行内形态不变（分数档星标、其余类型语义胶囊标签）。虚构叙事此前的 `clear_score`（通关分数线）此前只在折叠楼层头里逐层重复；现在移到**层面板右栏**，与左侧目标列共用 `.nk-egd-head` 两栏原语（基准页右栏是「通关奖励」，形态同源）。

5. **赛季规则右栏 = 只放逐层取不到的值（`renders.seasonRules()`）**：层记录的 `countdown` 直接上半场卡片（新增「回合」行，判据 `v-if="countdown"`，末日幻影层恒为 0 故基准页零变化）；赛季级 `countdown` / `clear_score` 只在**与每层取值不完全相同**时进右栏。忘却之庭的赛季回合上限 30 = 逐层 30 → 右栏退场（值在卡片上）；虚构叙事的赛季回合上限 5（逐层为 0）与通关分数线 30000 → 两项都上屏。**这是决策 3 判据在数值项上的同一条规则**，不是第二个特例。

6. **层内敌方一律走敌方详情卡（用户裁决 Q3）**：`StageContent` 退化为纯「敌方配置」块（`EnemyCard`），`isBoss` / `label` / `headless` / `hideDamage` 四个 prop 全部删除——遗忘之庭 / 虚构叙事的星启看板本来就经 `EndgameBoard` 走敌方详情卡，层看板若继续用小图标格，同一页的星启 tab 与层 tab 会形态不同构。代价是层看板变长（忘却之庭每半场 5-7 敌、虚构叙事 7 敌，末日幻影 1-3 敌），换来弱点 / 抗性 / 韧性 / 速度 / 召唤物同屏可读。

7. **层名不落任何上屏位（沿用 ADR 0035 决策 2 的裁决）**：忘却之庭 / 虚构叙事的层名（「物竞天择其一」「借虚成真其二」）与层级子 tab 的「第 N 层」重复，随折叠楼层一并退场；**层名仍由数据产出**，只是本页不渲染。

8. **死形态同批删除**：`EndgameFloors.vue`（折叠楼层 + 展开全部 / 全部折叠）、`EndgameTargets.vue`（01/02/03 序号目标，ADR 0035 中性条曾为它保留）、`StageHead.vue`（场次标签 / 波次·敌数，改由看板头与「第 N 波」标签承担）、`renders.endgameGroups` / `EndgameGroup` / `ENDGAME_GROUP_LABELS`（分场次分组只剩基准页之外的扁平列表形态）与 `EndgameBuffGroup` 的 `label` prop、`renders.stageHasContent` / `stageDamageSummary` / `mergedMonCount`（折叠摘要专用），以及 `endgame-detail.css` 的 `.nk-egd-floor__arrow` / `__summary*` / `__body*` / `--open` / `__name` / `__stagehead` / `__stagelabel` / `__stages` / `__goals*` / `.nk-egd-pollchip__half` / `.nk-egd-group__label` / `.nk-egd-title-tool*` / `.nk-egd-floor__poll`（末两条是 ADR 0035 声称已删但仍在的死规则）。

9. **e2e 迁移而非删除（沿用 ADR 0033 记忆里的判据）**：ADR 0028 的父子层级刻度用例原先用忘却之庭的 `.nk-egd-floor__body-inner`（折叠体缩进 + 竖轨）与 `.nk-egd-floor__stagelabel`（子档场次标签）当锚点，两者都随折叠楼层退场。**契约保留、锚点搬家**：缩进 / 竖轨断言改挂战斗看板体（轨宽必须为 0）与异相仲裁卡体（轨宽必须 > 0），「父档 > 孙档」改为卡片名 > 「第 N 波」标签。配套把 `lastWaveMonster` 测试助手对齐产品判据 `renders.lastWaveBoss`（末波**第 1 只**，此前写成末波最后一只——忘却之庭层半场末波有多只时测出来的是另一只）。

## 后果

**正面**

- 三个层级页面同一套编排：赛季级区块 → 层 / 星启子 tab → 目标栏 → 战斗卡片行 → 单场看板；层 tab 与星启 tab 逐字同构。
- 忘却之庭页面从「12 个折叠楼层纵排」变为「一次一层」，单层信息在首屏内自洽；虚构叙事同。
- 每项事实在同屏只出现一次：等级 / 回合只在卡片，层级增益只在看板首块，赛季增益与逐层重复的那份整块退场，赛季维度数值集中到右栏。
- 敌方详情卡让忘却之庭 / 虚构叙事的层看板能读到弱点 / 抗性 / 韧性 / 召唤物，此前只有小图标格。
- 死形态一次性清完，`EndgameTierce` / `EndgameBuffGroup` / `StageContent` 三件都不再带「形态开关」，缺省形态唯一。

**负面**

- 层 tab 行在层数多的赛季会换行：忘却之庭 12 层在 1440px 下占两行、375px 下占三行（`flex-wrap` 兜底，零横向溢出）。**这是「按层导航」相对「折叠列表」的固有代价**：读者要横向扫 tab 才能定位层，而折叠列表一屏能看到全部层名。
- 层名（「回忆其一」这类官方层名）本页不再可见，读者只能在子 tab 读到「第 N 层」。
- 赛季级「通关分数线」（虚构叙事 30000）现在出现在**每个层 tab** 的右栏（一次只渲染一个层，同屏仍只有一份），与此前「每层折叠头都写一遍」同量级——但不再随 12 个折叠块滚过去。
- 忘却之庭 / 虚构叙事的非激活层 DOM 不存在（tab 的语义使然）：站内检索与客户端取证只能看到当前层。AI 快照不受影响（`*.catalog.json` 独立生成，本轮零数据改动）。

**中性**

- 类名 `.nk-egd-floor__*` 现在有一半只服务异相仲裁（`EndgamePeak` 内联那份敌方行）；未改名，避免动 20 余处 e2e 选择器。
- `EndgameFloor.vue` 沿用 `.nk-egd-lvl` 容器类（`guards.spec.ts` 的不变量锚点之一），文件名与类名暂时不同源。
- `levelTabFloor` / `buildLevelTabs` 的判据只看 `floor_details` 与 `tierce`，与 `modeKey` 无关——层数、星启有无全部由数据派生。
- 详情页仍无像素基线；本轮 `visual.spec` 未跑（AGENTS 禁全量 e2e）。

## 替代方案

| 方案 | 为何未采用 |
|---|---|
| 忘却之庭保留折叠楼层、只把层内块序对齐基准页 | 用户明确要「参考末日幻影的排版」；保留折叠就仍是两套编排，且 12 层纵排的长度问题原样保留 |
| 三种模式共用「折叠列表 + 单场看板」子卡片 | 子 tab 是 ADR 0030 已立并经三轮迭代的形态，另造折叠版等于第三套编排 |
| 赛季增益按层复制进每个层看板 | 忘却之庭三条同文增益会变成 12 份；虚构叙事三条赛季机制也会在 4 个层 tab 各渲染一次（用户裁决 Q2 选了「同文则不重复」） |
| 赛季增益无条件保留在赛季级 | 忘却之庭会在赛季区块与 12 个层看板各出现一次「记忆紊流」，共 13 次（用户裁决 Q2 否掉） |
| 通关分数线只留在赛季级某处，不进层面板 | 它与分数档目标同属「打分」语义；放在目标栏旁边比分散在另一区块更可读，且不需要为它新造一个带序号的区块 |
| 敌方配置继续用小图标格（忘却 / 虚构） | 同页星启 tab 已是敌方详情卡，两种形态并置属不同构（用户裁决 Q3 否掉） |
| 星启在忘却之庭 / 虚构叙事仍作页面级区块 | 子 tab 已承载层，星启再作区块就是「两种同层级只保留一个可见」的机制叠加（ADR 0030 决策 2 已否决过一次） |
