# 主题色统一为单强调色通道（货币战争取消独立色阶）

**Status**: Accepted（已实现）

## Context

自 [ADR 0007](0007-currency-war-mode.md) 起，货币战争模式（`/currency/*`）经 `<html data-theme="cw">` 覆盖整套 CSS 变量实现「同壳换肤」；[ADR 0011](0011-全局色彩管理-黑与紫-黑与金.md) 把它固化为**双色约束**：常规 = 一个色相、货币战争 = 另一个色相。强调色可切换后，两个模式各有一套别名层与色板：

- 常规：别名层 `--th-*`，开关 `data-accent`，5 个色板（赤陶缺省 / 橄榄青 / 雾霭蓝灰 / 暖沙棕 / 暮山紫），实现 `src/lib/theme.ts`。
- 货币战争：别名层 `--cwth-*`，开关 `data-cw-accent`，5 个色板（香槟金缺省 / 玫瑰金 / 铂银 / 翡翠 / 赤铜），实现 src/lib/cw-theme.ts（本次已删除）；`[data-theme="cw"]` 块除主色外还重映射 `--surface` / `--card` / `--text*` / `--border*` / `--highlight` / `--metric-val` / `--gold` / `--gold-sem` / `--rarity-5` 与整套外壳 / 抽屉 / 头部 / 输入框令牌（30+ 条）。

代价与漂移：

1. **同一站点两套主题色并无产品理由**——两片页面属于同一个站点、同一套版式与同一套信息语言，色相差异只带来「像两个站」的观感成本。
2. **每加一个强调色要改三处 ×2 套**（原始层色阶 + `[data-accent]` / `[data-theme="cw"][data-cw-accent]` + 两个 TS 色板表），任一处漏改即静默漂移。
3. **对比度门禁只覆盖 `:root` 与 CW 块**，常规的 4 个非缺省色板从未被守卫验收；CW 块本身还引入了低不透明度文字（`--text3` = 72% 混色后再 52% 透明），在彩色底上不可控。
4. 货币战争页面里沉淀了一批**为浅金填充准备的补偿**（`[data-theme="cw"] … { color: var(--blk-900) }`、gold 色阶的 scope/seg/step 局部令牌、进度条与激活项覆盖）——它们只在「主色是浅金」时成立。

用户裁决：**两种模式的主题色统一**，方向为「全站跟随常规强调色（缺省赤陶）」，且货币战争的独立强调色切换器**整体退场**。

## Decision

1. **别名层收敛为一条**：删除 `--cwth-*` 定义与全部消费点；主题色阶别名层只剩 `--th-*`，随 `<html data-accent>` 切换（缺省赤陶）。全站（含货币战争）共用一套 5 色板。
2. **删除 `[data-theme="cw"]` 颜色层**：整层语义重映射（30+ 令牌）与 4 个 `[data-cw-accent]` 色板一并退场。`<html data-theme="cw">` **保留为模式标记**（`meta.cw` 仍驱动导航配置与目录页，e2e 亦以它断言模式）——但它不再重映射任何颜色。
3. **删除货币战争专属切换器**：src/lib/cw-theme.ts 与其测试、`bootstrap.ts` 的 `initCwAccent()`、设置页 02 区块（含 `HSR_WIKI_CW_ACCENT` 存储键）整体退场；设置页只剩 01 主题色 / 02 开拓者形态两个区块。
4. **货币战争页面的主题位改用语义令牌**：三个页面样式表里 40 余处 `--cwth-*` 按语义替换——大面积填充 / 描边走 `--primary`，文字与细线亮端走 `--metric-val`，梯度端走 `--accent`；为该模式浅金主色而写的一批深色文字补偿（`.is-on` / `.is-active` 的 `color: var(--blk-900)`、进度条与激活项覆盖、scope/seg/step 局部令牌覆盖）同批删除，改由各页面原有的语义声明承担。
5. **领域位不合并**：`--cw-*`（派系 / 战斗 / 特殊 / 稀有度）、`--crole-step-*`、`--crole-buff`、`--gold-*` 等数据语义色保持原样——本次合并的是**主题层**，领域色豁免继续有效（ADR 0011 决策 4 未被修订）。
6. **对比度门禁升级为「全色板验收」**：`tools/check-contrast.mjs` 从「读 `:root` + CW 块」改为「读 `:root` + 全部 `[data-accent="…"]` 色板（每块叠在 `:root` 基底上解析）」——单通道之后，任何一套色板都可能在换色后才露馅，故必须逐色板强制。

## Considered Options

- **保留两个切换器但色板/色值一致**：结构不动、改动最小，但站内长期留两套等价设施，且「新增强调色要改六处」的成本与漂移风险不变。被拒（用户裁决为「整个退场」）。
- **全站统一为香槟金**：把站点身份色改成金（黑与金）。被拒——常规模式的赤陶缺省与既有 4 个色板、以及大量以赤陶为基准校准过的对比度结论都要重做，收益仅是换个色相。
- **保留 `data-theme="cw"` 的颜色层但指向 `--th-*`**：等于留一层空壳重映射，仍会被后来者当成「模式可以换色」的入口。被拒——**留一个不再生效的换色层比删掉它更危险**。

## Consequences

- 货币战争页面的观感由「黑与金」变为「黑与当前强调色（缺省赤陶）」；`--gold` / `--gold-sem` / `--rarity-5` 在货币战争页面不再走暗铜降阶，与常规页一致（领域金不再需要与主题金错开）。
- `--primary-glow` 在货币战争页面由 25% 回到 10%——原来的 25% 是为金属金补材质感，赤陶下 25% 会读成光晕溢出。
- 页面级补偿删除后，货币战争页面的激活态文字重新由 `--text-bright` 承担（原为浅金底上的 `--blk-900`）——对比度由门禁与 axe 复验。
- 存储键 `HSR_WIKI_CW_ACCENT` 成为孤儿键：不再读写，也不主动清理（清理由浏览器存储策略承担，删除动作会引入一次性迁移代码，不划算）。
- 修订 [ADR 0007](0007-currency-war-mode.md) 的「全壳主题换肤」与 [ADR 0011](0011-全局色彩管理-黑与紫-黑与金.md) 的「双色约束」；[ADR 0012](0012-色彩代码架构管理-事实链与三道闸门.md) 的四层令牌描述中别名层由两条并为一条。
- 术语：`CONTEXT.md` 的「双色约束」改为「单强调色通道」，「强调色」「主色族」「领域色豁免」三条同步改写。
