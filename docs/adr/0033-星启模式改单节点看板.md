# 0033. 星启模式改单节点看板

## 状态

`accepted`（**已实现**：`EndgameTierce` 把原先纵排的三张节点卡改为「节点子切换 + 单节点看板」——一次只渲染当前节点，块序按游戏内星启看板重排（行头 → 末法余烬 → 首领特性 → 敌方配置 → 赛季增益）；推荐属性从场次行提到看板行头（`StageContent` 新增 `hideDamage`）；首领特性由 4 张卡片改为横向标签行 + 一次展开一条描述（`EndgameTraitGroup` 新增 `tabs`）；污染等级徽标挂在首领特性行右侧（`head-end` 插槽，无该行的节点退回行头）；面板级目标区按官方文案改名「星级目标」并用星标行；新增共享胶囊标签原语 `.nk-egd-pilltabs` / `.nk-egd-pilltab` 与 `tabs.ts` 的 `tabNextIndex`。**修订 [ADR 0030](0030-末日幻影详情页层级星启子tab.md) 决策 2 的星启面板结构、[ADR 0032](0032-星启节点按完整场次渲染.md) 决策 4 的卡形与决策 7 的「卡形统一」；决策 8 另修订 [ADR 0029](0029-末日幻影赛季增益分场与首领特性.md) 的中性条（「可用增益」标签全站移除），决策 9 修订 [ADR 0032](0032-星启节点按完整场次渲染.md) 决策 5 与 [ADR 0031](0031-末日幻影层级敌方取实际战斗数据.md) 决策 3（节点号上屏 + 末波首领头像，「同第 N 层」标注退场），决策 10 再把子切换改为三张并列卡片（末波首领图 + 推荐属性 + 等级）并从行头撤掉等级与推荐属性，决策 11 再把行头整块退场，决策 12 再把首领特性从横向标签行改为「整组一张卡片 + 组内逐条平铺」（`tabs` prop / `.nk-egd-pilltab*` / `.nk-egd-trait--tabbed` / 固定 id 全部下线），决策 13 再去掉星启看板的两条模式色竖线（整组卡片的左沿 + 看板体父子层级竖轨，缩进保留）**）

## 背景

1. **用户给出游戏内星启模式看板截图**，要求「参考图片，重新编排末日幻影详情页面，星启模式板块排版」。
2. **当时的站点形态（ADR 0032）与截图差三点**：① 游戏内看板一次只看一个节点（头部是「难度 04 / 节点一 | 仙客天狼 / 等级 / 建议属性」），站点把三场摊成一条长列表（3020 实测面板高 **4135.7px**）；② 游戏内块序是 等级·建议属性 → 末法余烬 → 首领特性 → 通关/星级目标，站点是 推荐属性 → 敌方配置 → 赛季增益 → 首领特性 → 可用增益；③ 游戏内首领特性是横向标签行（右端挂污染等级），站点是 4 张纵排卡片。
3. **数据层不缺字段**：`tierce.nodes[*]` 已带 `damage` / `monsters` / `level` / `countdown` / `buff` / `invasion` + `origin` 场次键（ADR 0032），赛季级 `buff_groups` / `boss_traits` 按 `origin` 取——本轮**零转换器改动、零产物变化**。
4. **一处数据缺口被本轮挡下**：截图里的「通关目标：击败 3 个首领」在上游没有对应字段（13 个星启赛季的 `targets` 全是 4 档 `TOTAL_SCORE` 分数，`ChallengeMazeTierce` 系表也没有目标类型字段），按「展示文本必须来自数据源」不落，只把四档分数按官方文案改称「星级目标」。

## 决策

1. **一次一个节点**：星启面板加一行节点子切换（上半场 / 下半场 / 星启附加关，`role="tablist"` + roving tabindex + 方向键），下方只渲染当前节点的看板；节点数 ≤ 1 时不渲染该行、看板也不带 `tabpanel` 角色。看板沿用 ADR 0028 的父子层级刻度（父档主字**决策 11 后由节点卡片名承担**，`__nodebody.nk-egd-children` 是子档缩进与竖轨），故 `__node` / `__nodehead` / `__nodebody` 类名保留（`__nodehead` 只承载退无可退的污染徽标），`__nodes`（`<ol>`）与节点间分隔线退场。
2. **块序按游戏内看板**：行头（场次 + 同第 N 层 + 等级/回合 + 推荐属性 + 波次·敌数）→ 末法余烬（`EndgameFloorBuff`）→ 首领特性 → 敌方配置（`StageContent`，其推荐属性行随之退场）→ 赛季增益。推荐属性因此从场次行移到行头。（**决策 9 改**：行头只留节点号——场次文案与「同第 N 层」同源标注退场。**决策 11 再改**：行头整块退场，看板以末法余烬为首块。）
3. **首领特性改横向标签行**：`EndgameTraitGroup` 新增 `tabs` prop（缺省 = 原有逐条平铺），开启后渲染标签行 + 当前标签的描述面板。**只对星启看板开启**——层 tab（`EndgameBossFloor`）保持 4 张卡片平铺：层节点是「这一层吃哪些机制」的扫描位，星启看板是「这一个节点看什么」的聚焦位，用途不同；两种形态留在同一组件内，避免复制卡片模板。（**已被决策 12 修订**：横向标签行整体下线——星启看板改为「整组一张卡片 + 组内逐条平铺」；层 tab 的「每条一卡」不变。）
4. **污染等级徽标跟着首领特性行（截图位）**：`EndgameTraitGroup` 新增 `head-end` 插槽，星启看板把 `.nk-egd-pollchip` 投进去（`margin-left: auto` 落在 `.nk-egd-group__tail`）。**无首领特性的节点没有这一行**（忘却之庭 / 虚构叙事的星启节点、未来缺 `boss_traits` 的赛季），徽标退回看板行头——否则该节点会整块丢掉污染信息（**决策 11 后，行头就是这一枚徽标的专属容器**）。末日幻影 5 个星启赛季每个节点都有 4 条特性，实测徽标总在首领特性行。
5. **面板级目标区改名「星级目标」**：四档分数即游戏内星级目标，行首改星标图标（复用 `TARGET_TYPE_SVG.TOTAL_SCORE`，`fill: currentColor` + `--highlight` 令牌）；非 `TOTAL_SCORE` 类型仍走原语义胶囊标签。
6. **胶囊标签行收口为共享原语**：`.nk-egd-pilltabs` / `.nk-egd-pilltab` / `--active` 单点声明在 `endgame-detail.css`，节点子切换与首领特性两处消费；方向键逻辑抽到 `src/app/endgame/tabs.ts` 的 `tabNextIndex`，`EndgameLevelTabs`、节点子切换、首领特性三处共用（层级子 tab 的行为不变，仅去重）。
7. **三模式统一、零转换器改动**：`EndgameTierce` 是共享组件，忘却之庭 / 虚构叙事的星启区块一并变成单节点看板（沿用 ADR 0032 决策 7 的理由：「三模式同构，不为末日幻影另开分支」）；数据、快照、字段零变化。
8. **「可用增益」标签全站移除（用户裁决）**：末法余烬块在站点有 3 处渲染位——`EndgameFloorBuff`（层尾与星启看板共用）、`EndgamePeak` 内联一份（异相仲裁的层级增益）。用户看完星启看板截图后裁决**全站移除**该标签：只留图标 + 增益名（`__buffname`）+ 效果描述，两处模板各删一行，`.nk-egd-floor__bufflabel` 同步从 `endgame-detail.css` 的两处选择器组（基础标签样式 / 0.72rem 字号档）删除——**不留死选择器**。**修订 [ADR 0029](0029-末日幻影赛季增益分场与首领特性.md) 中性条「未改：楼层内的『可用增益』保持原名」**。
9. **节点号上屏 + 末波首领头像（用户裁决）**：节点子切换与看板行头改回**节点号口径**（节点一 / 节点二 / 节点三，游戏内文案写法），每个胶囊带该节点的**末波首领头像**——`monsters` 里 `wave` 最大那一波的第 1 只，经 `cdnUri('monstermiddleicon', …)` 加载，24px 圆头像 + 模式色描边（`.nk-egd-pilltab__avatar`，与「敌方配置」的首领头像同一套取图路径）；同批**「同第 N 层」同源标注退场**（行头只留节点号）。**修订 [ADR 0032](0032-星启节点按完整场次渲染.md) 决策 5「节点编号退场」与 [ADR 0031](0031-末日幻影层级敌方取实际战斗数据.md) 决策 3「节点 1/2 标同源关系」**。（**形态部分已被决策 10 修订**：胶囊 + 24px 头像 → 三张并列卡片 + 72px 首领图；节点号口径、末波首领判据、「同第 N 层」退场不变。）
10. **节点子切换再改「三张并列卡片」（用户裁决）**：三张等宽卡片一行取代胶囊标签行——每张 = 末波首领图（同一 `monstermiddleicon` 图源，72px 圆，`.nk-egd-nodecard__fig`）+ 节点号 + **推荐属性**（`elemRow(nd.damage)` 的元素图标）+ **敌人等级**（`nd.level`）；同时**看板行头去掉等级与推荐属性**（卡片已承载，避免同一看板两处重复），行头只留 节点号 + 污染徽标（无首领特性行时）+ 回合 + 波次·敌数（**决策 11 改**：这一行整块删除）。手机端（<768px）**卡片内改上下排版**（图 44px 在上，节点号 / 推荐属性 / 等级依次在下、居中），三卡按 `flex: 1 1 0` **均分一屏宽**（不做横向滚动：320 / 375 / 412px 实测 `scrollWidth == clientWidth`、卡内无溢出），字号随之下调一档（`__name` 0.88 / `__val` 0.84 / `__label` 0.68）、元素图标 14px。**修订决策 9 的胶囊形态与决策 10 首版的手机横向滚动方案**；`.nk-egd-tierce__elems`（行头推荐属性容器）与 `.nk-egd-pilltab__avatar` / `--icon` 随之下线。
11. **看板行头整块退场（用户裁决）**：`#egd-tierce-board` 的 `<header class="nk-egd-tierce__nodehead">` 不再渲染节点号与波次·敌数——**节点身份由上方节点卡片承担**（看板 `aria-labelledby` 本就指向当前卡片，读屏口径不变），波次信息由每个「第 N 波」标签承担。行头**保留为「无首领特性节点的污染徽标容器」**（`v-if="activeNd.invasion && !activeTraits.length"`，即决策 4 的退回位），否则忘却之庭 / 虚构叙事这几类节点会整块丢掉污染信息。随之退场：`.nk-egd-tierce__nodezh`（基础档 + 手机重述两处声明）、`.nk-egd-tierce__nodehead .nk-egd-floor__moncount` 的 `margin-left: auto`、`EndgameTierce` 的 `monCountLabel` 导入；`StageHead` 的注释同步去掉「星启节点」这处提级位（层节点 `.nk-egd-lvl__nodehead` 不受影响）。**修订决策 1 的「`__nodezh` 父档主字」与决策 10 的行头口径。**
12. **首领特性改「整组一张卡片 + 组内逐条平铺」（用户裁决，下线决策 3）**：`EndgameTraitGroup` 新增 `card`（反向语义：缺省 = 每条特性各一张卡片），开启后整组共用一个卡片容器 `.nk-egd-traits--card`——卡形（填充 / 1px 四边描边 / 圆角，**中性色，不设模式色左沿**，见决策 13）整组承担，组内 `.nk-egd-trait` 的填充 / 描边 / 圆角 / 内距 / 入场动画全部归零，条目之间只靠行距（容器 16px > 条目内 8px）分节、不画分隔线。**只对星启看板开启**：层 tab（`EndgameBossFloor`）保留「每条一卡」的扫描位形态（ADR 0034 决策 5 的 `traitsGap` / `traitPad` 同族契约因此不变）。随之下线（消费方与专用形态同时消失，不留死选择器）：`tabs` prop 及其标签行分支、`.nk-egd-pilltabs` / `.nk-egd-pilltab` / `--active` / `:hover` 四处声明与字号收口块里的 `.nk-egd-pilltab` 条目、`.nk-egd-trait--tabbed`（基础档 + 手机档重述）、`#egd-trait-tab-N` / `#egd-trait-panel` 固定 id（决策 6 的胶囊原语命名债务与「两份标签行撞 id」风险一并消失）；`tabs.ts` 的 `tabNextIndex` 仍被层级子 tab 与节点卡片两处消费，保留。污染等级徽标的位置与退回判据（决策 4）不变。
13. **星启看板去掉两条模式色竖线（用户裁决）**：用户在手机截图里点出左侧两条粉色竖线并要求全部移除——① **整组单卡的左沿**：`.nk-egd-traits--card` 不再覆写 `border-left`，与赛季增益 / 末法余烬同一套中性 1px 发丝描边；② **看板体的父子层级竖轨**：`.nk-egd-children::before` 的轨道宽度提为消费侧开关 `--eg-rail-w`（缺省 `3px` 仍是 [ADR 0028](0028-终局详情页父子层级刻度.md) 决策 2 的单点声明），`.nk-egd-tierce__nodebody` 覆写为 `0`——**只影响星启看板**，楼层折叠体（`.nk-egd-floor__body-inner`）与异相仲裁（`.nk-egd-peak__body`）的轨线逐字不变。**缩进保留**（`--eg-indent` 16px / 手机 12px，左基准与 ADR 0028 刻度不变）：本轮删的是「线」不是「档」，看板内区块仍由「区块标题下沿发丝线 + 区块节奏」分节。**修订 [ADR 0028](0028-终局详情页父子层级刻度.md) 决策 2 在星启这一处的落地、[ADR 0034](0034-终局节点详情面板字阶与区块节奏.md) 决策 3 的「节点体整块走缩进与竖轨」。**

## 后果

**正面**

- 3020 星启面板高度 **4135.7 → 1269.4px（-69%）**，一个节点的全部信息一屏可读完，节点间切换一次点击。
- 块序与游戏内看板一致：头部（等级 / 建议属性 / 敌数）→ 末法余烬 → 首领特性（+ 污染等级）→ 敌方配置 → 赛季增益。
- 首领特性从 4 张纵排卡片收到「标签行 + 一条描述」：机制名一排可比、选中的那条展开全文（`#1`/`#2` 参数仍按 `ParameterList` 渲染，如坚防守备 50% / 100%）。（**决策 12 修订**：标签行下线，星启看板改为整组单卡、四条说明同屏平铺。）
- 污染等级徽标与首领特性同排（截图位），不再挤在场次行头；层 tab 的 `StageHead` 徽标不受影响。
- 「星级目标」+ 星标行与游戏内文案一致，四档分数一次看全。
- 节点子切换带末波首领头像（决策 9）：末日幻影三个节点 = 三个首领本体，忘却 / 虚构 = 各自压轴首领，切换前就能认出是哪场。
- 三张并列卡片（决策 10）把「打谁（首领图）+ 什么属性 + 多少级」提到切换前：三个节点可同屏对比，不再需要点开每个节点才知道难度与属性差异。行头随之瘦身（去掉重复的等级与推荐属性），决策 11 后整块退场。

**负面**

- **首领特性一次只显示一条描述**：四条机制的全文不同屏（用户按截图选的形态）；要通读四条可在层 tab 看（那里保持平铺）。（**决策 12 撤销本条**：星启看板改整组单卡平铺，四条全文同屏；保留原文以记录当时的裁定与代价。）
- **忘却之庭 / 虚构叙事的星启区块被动改形**（与 ADR 0032 同类的「三模式统一」代价）：三节点纵排 → 单节点看板，页面变短但多一层点击。
- **「同第 N 层」同源标注退场（决策 9）**：看板不再标出「节点一/二 = 常规末层上下半场」的同源关系（ADR 0031 立这条标注的目的），要对照得切回层 tab；三模式一并生效。
- **头像对忘却之庭 / 虚构叙事是「末波首领」而非全阵容代表**（一个节点 3–7 敌，波 1 是小怪）：这是「一眼认出这是哪场」的判据，不是阵容摘要。
- 节点号一度在面板里出现两次（卡片 + 看板行头，与游戏内看板同形）；**决策 11 后行头退场，节点号只在卡片上出现一次**。
- **看板内不再复述节点号与波次·敌数（决策 11）**：切到某节点后看板自身不写「这是哪个节点」，波次信息只剩各波标签（单波时看不出「共几波几敌」）；换来的是首屏少一行、同一事实只出现一次。
- **卡片行占用首屏约 98px（桌面）/ 144px（手机）**：手机端换取的是「三卡一屏全见」，代价是卡片内纵向排四段信息；若要压缩高度，回退点是 `.nk-egd-nodecard__fig` 尺寸与 0.68rem 标签档。
- 决策 10 后**行头不再显示等级与推荐属性**（只在卡片上）、决策 11 后**行头整块退场**：切到某个节点后，看板自身不复述节点号与属性，读的时候视线要回到上方卡片行。
- 手机端三卡等分一屏宽：**320px 下卡宽仅 91px**（最密的一张卡 4 枚 14px 元素图标 + 4 字标签），再窄或再来一项信息就会溢出——这是「一行全见」的硬边界，不是可继续压的空间。
- **推荐属性从场次行移到看板行头**：`StageContent` 因此新增 `hideDamage`（缺省显示），星启看板与层 tab 的场次行不再同形。
- 面板高度随选中节点变化（附加关与上下半场内容不同），下方相邻赛季导航的位置会随节点切换跳动。
- 节点选择不进 URL：刷新或从相邻赛季跳回落到第一个节点。当前无深链需求；若要深链节点需补 state + 快照契约（另开）。

**中性**

- `__nodes` 列表样式与 `.nk-egd-tierce__node + .nk-egd-tierce__node` 分隔线随三节点纵排退场（`+` 选择器已不再命中）。
- 新增 API 三处：`tabs.ts` 的 `tabNextIndex`、`EndgameTraitGroup` 的 `tabs` / `head-end`、`StageContent` 的 `hideDamage`。（`EndgameTraitGroup` 的 `tabs` 已由决策 12 换成 `card`；`head-end` 与 `tabNextIndex` 仍在使用。）
- AI 快照不受影响（星启在快照里只占一行，字段零变化）；详情页无像素基线。
- `EndgameTraitGroup` 的 `tabs` 形态带 `#egd-trait-tab-N` / `#egd-trait-panel` 固定 id——同一页面同时渲染两份「标签行形态」会撞 id（当前只有星启看板一处消费）。（**决策 12 后该形态整体下线，固定 id 与撞 id 风险一并消失。**）
- `.nk-egd-floor__bufflabel` 与「可用增益」文案随决策 8 全站退场（`EndgameFloorBuff` + `EndgamePeak` 内联那份 + 两处 CSS 选择器组）；异相仲裁的层级增益与楼层**仍是两份实现**，本轮只同步删标签、未合并成组件。

## 实施记事（可复用的四个坑）

- **Vue 的布尔 prop 缺省是 `false`，不是 `undefined`**：`StageContent` 首版用 `showDamage?: boolean` + `showDamage !== false` 判定，编译出的运行时 prop 类型是 `Boolean`，未传时被强制转为 `false` → **层 tab（`EndgameBossFloor`）的推荐属性行整块消失**。改为反向语义 `hideDamage?: boolean` + `!hideDamage`（缺省 = 显示）。e2e 里「星启节点 1 的推荐属性 `innerHTML` 与第 4 层逐字相同」这条断言直接把它顶了出来——**枚举型的布尔 prop 一律用「否定式命名 + 缺省显示」或显式 `default`**。
- **「元素截图」只画视口内的像素**：面板高于视口时 `locator.screenshot()` 的其余区域是空白（页内滚动容器不在元素内），量高要用 `boundingBox()` / `getBoundingClientRect()`，截图前先把视口调高。
- **CDN 图的 `naturalWidth` 断言必须 `expect.poll`**：节点头像来自 CDN，`evaluateAll(el => el.naturalWidth)` 是**一次性取值**——2 worker 并行下图片常晚于断言回来，单跑通过、并发跑失败（本次实测：`:462` 在 `--grep endgame` 失败、单测通过）。凡「等图出位图」的断言一律包 `expect.poll(..., { timeout: 15_000 })`。
- **`loading="lazy"` 的图在横向滚动区外根本不取图**：改成三张卡片行后，手机端第三张卡在 `overflow-x: auto` 容器视口之外，`naturalWidth` 恒为 0——**`expect.poll` 也救不回来（不是慢，是永不加载）**。修法是逐张 `scrollIntoViewIfNeeded()` 再 poll（e2e 里对三张各 poll 一次）。凡断言「滚动容器里的图已出图」，先让元素进视口。
- **要「删掉一条 CSS 伪元素」又要保住既有断言口径，就把它的几何提成令牌**：星启看板去轨首版写 `.nk-egd-tierce__nodebody::before { content: none }`——`content: none` 之下伪元素不生成，`getComputedStyle(el, '::before').width` 便不再反映这条声明（e2e 量到的是宿主元素口径），断言直接红在「期望 0、实得 3」。改为 `width: var(--eg-rail-w)`（缺省 3px）+ 消费侧覆写 `--eg-rail-w: 0`：**同一个探测点（`::before` 计算宽度）继续有效**，且「这一层画不画轨」成了单点可读的开关。判据：**凡是断言依赖某个计算值的元素，别用「不生成该元素」的方式删除它——要用「让它算出来为 0」的方式。**
