# 货币战争角色转换模块字段分析

> **定位**：货币战争（Grid Fight）角色数据转换的活文档——输出字段 → 源字段 → 转换逻辑 → 消费方 → 验证状态。
> 与 [角色转换模块字段分析](./角色转换模块字段分析.md)（常规模式）互补；本报告聚焦 `GridFight*` 数据体系。
>
> **深度审计**：2026-08-02（分支 `feature/currency-converter-audit`）

---

## 一、范围与基准

### 范围

| 模块 | 输出 | 审计级别 |
|------|------|----------|
| `currency.py` | `currency/role.json`（75 角色）+ `currency/role/{id}.json` | **核心全量** |
| `currency_catalog.py` | `currency/traits.json`、`equipment.json` | 关联核查 |
| （排除） | `portals.json` / `augments.json` / `season.json` | 与角色无关 |

### 基准（三层对比法）

```
源字段全集 ⊇ 转换器读取 ⊇ 输出 ⊇ 前端消费
```

- **前端消费 ⊄ 输出** → 直接影响 bug（当场修复）
- **源字段 - 读取** → 遗留字段（A/B/C 分级：A=游戏内用户可见建议补全、B=次要记录、C=忽略）
- 语义性：已知陷阱清单专项核查（HealOrShieldDisplay / IsInBook / SP 语义 / ChargeType / 术语）

### 抽样角色（7 个，覆盖机制维度）

| 角色 | 覆盖分支 |
|---|---|
| 三月七（1001） | 唯一 `Shield` 动效 + 无专属装备 + 后台 |
| 布洛妮娅（1102） | 前台输出基线 |
| 姬子（1003） | 专家（IsExpert）+ EnergyBar 充能 + 后台 |
| 停云（1106） | 专家 + 无专属装备 |
| 开拓者（8007） | CW 开拓者形态（命名改写） |
| 阿格莱亚（1412） | 随从角色 |
| 昔涟（1415） | 最新版本 + 随从 + 前台 |

> 注意：希儿（1101）**不在货币战争图鉴**（CW 角色为独立 ID 集合）。

## 三、role/{id}.json（角色详情）

### 3.1 顶层

与列表字段一致（id/avatar_id/name/rarity/front_back_type/heal_or_shield_display/charge_type/max_sp_icon/is_expert/trait_list/traits），另含：

| 字段 | 说明 | 验证 |
|------|------|------|
| `traits` | 完整羁绊（含 `layers` 层级效果，见 3.6） | ✅ |
| `stars` | 星级矩阵（见 3.2） | ✅ |
| `rank` | 后台星魂列表（见 3.4） | ✅ |
| `equipment` | 专属光锥列表（见 3.5） | ✅ |

### 3.2 stars（星级矩阵）

结构：`{ 星级: StarNode }`，星级数 3~4 不等（40 角色 3 星 / 35 角色 4 星）。

| `star` | `Star` | — | ✅ |
| `front_one_word_desc` / `back_one_word_desc` | `FrontOneWordDesc` / `BackOneWordDesc` | TextMap | ✅ |
| `front_power_base` / `back_power_base` | 同名 | `unwrap`（基础强度） | ✅ |
| `back_speed_rewrite` / `back_speed_added_ratio` | — | **恒 null**（源表无此字段，CDN 兼容占位） | ✅ |
| `back_energy_bar` / `back_max_sp` / `back_initial_sp` / `back_initial_energy_bar` | 同名 | `unwrap`（后台能量条体系） | ✅ |

### 3.3 skill 对象（front/back/servant 共用）

| 字段 | 源字段 | 要点 | 验证 |
|------|--------|------|------|
| `id` / `name` / `desc` / `simple_desc` | `SkillID` / `SkillName` / `SkillDesc` / `SimpleSkillDesc` | TextMap；desc 清洗（保留字面 `\n`） | ✅ |
| `type` | `SkillTypeDesc` | TextMap（如"战技"/"终结技"），空转 null | ✅ |
| `tag` | `SkillTag` | TextMap，空转 null | ✅ |
| `sp_base` | **`SPBase`** | **本次修复**：输出技能能量产生值（5/10/20/30/40…），缺失 null——此前恒 null 致前端 SP 区块死代码 | ✅ 已修复（189/811 有值，全部与源一致） |
| `bp_need` / `bp_add` | `BPNeed` / `BPAdd` | `unwrap`；**语义 2026-08-15 修正**：BPNeed -1 = 不消耗哨兵（普攻/终结技/天赋，非产出——大世界终结技 1830 条全为 -1 佐证），正值 = 消耗 N；产出语义在 BPAdd（1 = 获得 1 战技点，仅 4 角色普攻带值） | ✅ |
| `show_stance_list` | `ShowStanceList` | 逐项 `unwrap` | ✅ |
| `skill_combo_value_delta` | — | 恒 null（占位） | ✅ |
| `extra` | GridFightBackSkillExtraDesc | 命中时 `{condition:{name,desc,param}}`（触发条件说明） | ✅ |
| `level` | — | 恒 `{"1":{level:1, param_list}}`（CW 技能无多等级） | ✅ |

> 参数语义：`SPMultipleRatio`（全局常量 0.5）为充能倍率，无逐技能区分度，**仍不输出**；前端展示"SP 值"取 `sp_base`（能量产生值）。
