# 0035. 末日幻影层 tab 改「半场卡片 + 单看板」

## 状态

`accepted`（**已实现**：`EndgameBossFloor` 由「层标题 + 两个纵向半场节点 + 层尾末法余烬 + 层尾挑战目标」改为「层标题 + 面板顶部两栏（星级目标｜末法余烬）+ 半场卡片行 + 单半场看板」，块序与卡片形态与星启看板同形；抽出三个共享件 `EndgameStarTargets` / `EndgameNodeCards` / `EndgameBoard` 供层 tab 与星启看板共用，共享 CSS 原语由 `nk-egd-tierce__*` 改为中性名 `nk-egd-head*` / `nk-egd-startargets*` / `nk-egd-board*`；`renders.ts` 新增 `lastWaveBoss()`；删除「每条特性一卡」死形态与 `EndgameTraitGroup` 的 `card` / `label` 两个已无消费方的 prop。**修订（2026-10-02，用户看过页面后：层标题整行移除、末法余烬改随看板、星级目标合并为一行，见「修订」节）**；修订 [ADR 0030](0030-末日幻影详情页层级星启子tab.md) 决策 2 的层 tab 结构、[ADR 0031](0031-末日幻影层级敌方取实际战斗数据.md) 决策 1 的「两个纵向半场节点」形态、[ADR 0033](0033-星启模式改单节点看板.md) 决策 3 / 12 的「层 tab 保持每条一卡」与决策 6 的共享原语命名、[ADR 0034](0034-终局节点详情面板字阶与区块节奏.md) 决策 5 的同族内距契约**）

## 背景

1. 用户原话：「末日幻影详情页面，参考星启模式的排版，重构第 1 层到第 4 层的排版。」——同一页面的两个 tab 此前**形态不同构**：星启是「卡片行 + 一次一个看板」，层是「两个半场纵向铺开 + 层尾末法余烬 + 层尾挑战目标」。
2. 层与星启的数据粒度不同，这是唯一的真实约束：`3020` 实测 `stage1/stage2` 各自只有 `damage` + `monsters`（stage1 另带 `invasion`），**`level` / `countdown` / `buff` / `targets` 都在层记录上、两半场共用一个值**；层目标恒为 3 档 `TOTAL_SCORE`（22 赛季 88 层全等）、无通关奖励，层 `countdown` 22 赛季全部为 `0`（永不渲染）。层名在未发布赛季缺省（`3022` 四层均无 `Name`）。
3. 十项设计自由度走 DSH 问答卡片（Q1–Q10）逐轮收口，答案全部落盘后再动手；本轮零转换器改动、产物零变化。

## 决策

1. **层内上下半场改「半场卡片行 + 单半场看板」（Q1）**：一行两张卡片（`role="tablist" aria-label="半场"` + roving tabindex + 方向键），下方只渲染当前半场的看板。**不因「只有两场」退回纵向铺开**——同形的意义在于两个 tab 的阅读路径一致（切一次看一场），而非卡片数量。

2. **（**修订**：层标题随后整行移除，见「修订」节 1）** 卡面与星启节点卡片逐字同形（Q4 / Q9）：半场名（上半场 / 下半场）+ 末波首领图（`lastWaveBoss`，与星启同一判据）+ 推荐属性（该半场 `damage`）+ 等级（层记录 `level`，两张卡同值）。等级因此**只在卡片上出现**：层标题去掉等级与回合，只留「第 N 层 + 层名」（Q9）。等级是层共用值却仍在两张卡上重复一次，与星启三张卡同写 90 是同一形态，可接受；层标题再写一遍才是同屏第三处。

3. **（**修订**：末法余烬随后移入看板首块、星级目标一行随后被撤销，见「修订」节 2/3）** 面板顶部两栏：星级目标（左）｜末法余烬（右）（Q2 / Q5 / Q10）**：挑战目标从层尾提到面板顶部，并按官方文案改「**星级目标**」+ 行首星标（与星启同口径，01/02/03 序号退场）；末法余烬是层共用一块（两半场同值），**放面板顶部而非看板内**——放看板内会随子切换重复出现同一块内容。层级没有通关奖励，右栏就是末法余烬本体（自带增益名与描述），不新造栏名。

4. **层看板块序（Q5 / Q6）**：首领特性 → 敌方配置 → 赛季增益（末法余烬已上移，故不在看板内）。首领特性由「每条一卡」改**整组一张卡、组内逐条平铺**（与星启同形，Q6）。看板内**不复述半场身份**：无场次行头、无场次标签、无波次·敌数（波次信息由各「第 N 波」标签承担）——半场名只在卡片上出现一次。

5. **共享原语收口（实现纪律）**：层与星启现在消费同一套表单，故抽出 `EndgameStarTargets.vue`（星级目标列）、`EndgameNodeCards.vue`（卡片行）、`EndgameBoard.vue`（看板：末法余烬 → 首领特性 → 敌方配置 → 赛季增益，`buff` 缺省即层 tab 的顶部形态），层 tab 与星启看板各调用一次，**不留第二份模板**；共享 CSS 原语改名 `.nk-egd-head` / `__col` / `__label`、`.nk-egd-startargets` / `__star`、`.nk-egd-board` / `__body` / `__head`（原 `nk-egd-tierce__*` 在层面板里出现属命名错位）。`renders.ts` 新增 `lastWaveBoss()`（卡片「打谁」的唯一判据，星启节点与层半场同源）。

6. **（**修订**：徽标落点随后收口到看板头，见「修订」节 4）** 污染徽标随所属半场落在看板内（Q8）：层标题的逐半场徽标整块退场；看板沿用星启规则——挂在首领特性区块行头右端（`head-end` 插槽），无该区块时退回看板头容器（`stage.invasion && !traits.length`）。污染信息在层内只出现一次。

7. **看板体竖轨归零、缩进保留（Q7）**：`.nk-egd-board__body` 覆写 `--eg-rail-w: 0`（沿用 [ADR 0033](0033-星启模式改单节点看板.md) 决策 13 的开关），看板体仍走 ADR 0028 的缩进档（`--eg-indent` 16px / 手机 12px）；楼层折叠体与异相仲裁的竖轨不受影响。

8. **死形态与死 API 同批删除**：层 tab 改整组单卡后，「每条特性一卡」形态失去最后一个消费方 → 删除 `.nk-egd-traits--card` 与 `.nk-egd-trait` 的卡形声明（填充 / 四边描边 / 模式色左沿 / 圆角 / 入场动画 / 内距）、卡形整体落到 `.nk-egd-traits`，`EndgameTraitGroup` 的 `card` 与 `label` 两个 prop 一并退场（`EndgameBoard` 不传 label）。同时删除层 tab 退场留下的死选择器（`.nk-egd-lvl__poll` / `__node` / `__nodehead` / `__effects`、`.nk-egd-tierce__mons`）与死规则（`.nk-egd-lvl > .nk-egd-floor__goals`）。

## 后果

**正面**

- 两个子 tab 的排版同构：星级目标（一行）→ 卡片行 → 单看板，看板块序逐字相同；层内每项事实只出现一次（层共用值在卡片上的等级与看板首块的末法余烬，场次特有值在卡片与看板）。
- 层 tab 不再纵向铺开两场：3020 第 1 层从「两场全展开」变为「一次一场 + 两张卡片」，页面高度约减半；切半场一次点击。
- 卡片行把「打谁 / 什么属性 / 多少级」提到切换之前，两个半场可同屏对比（此前要上下对照两段结构）。
- 星启侧零行为变化（同一套共享件，`buff` 与面板头部由各自消费者传入）；AI 快照与所有数据产物零变化。
- 死形态 / 死 API / 死选择器一次清完，`EndgameTraitGroup` 只剩一种形态，不再有「形态开关的缺省给谁」的分叉。

**负面**

- 层 tab 的「一次只看一个半场」多出一次点击；不再有两场同屏的纵向对照（换取的是与星启一致与更短的页面）。
- 「每条特性一卡」的扫描位形态就此消失（ADR 0033 决策 12 曾为层 tab 保留它）；要通读四条机制仍在同一张卡内平铺，但不再有一卡一条的分隔感。
- 层标题不再显示等级与回合：回合 22 赛季 88 层恒为 0（无信息损失），等级改从卡片读到——「这一层多少级」的读法从标题行移到卡片行。**若未来某个赛季出现非 0 的层回合力上限，需要重新给它一个落点（当前无该实例，届时按星启的统计行形态加一行即可）。**
- 卡片行在桌面端占首屏约 98px；手机端两张卡等分一屏宽（每张卡内上下排版），是本形态的硬边界（两卡比三卡宽裕，320px 实测不横滚）。
- 部分层数据只登记一个半场时（`nodes` 少于 2），卡片行不渲染、看板也不带 `tabpanel` 角色——届时层内退化为单场看板（判据为 `cards.length > 1`）。

**中性**

- CSS 原语改名：`.nk-egd-tierce__head` / `__col` / `__headlabel` / `__targets` / `__star` / `__node` / `__nodebody` / `__nodehead` → `.nk-egd-head` / `__col` / `__label`、`.nk-egd-startargets` / `__star`、`.nk-egd-board` / `__body` / `__head`；星启只保留 `__stats` / `__stat` / `__val` / `__label` 与 `.nk-egd-reward*` 等星启专有件。
- `.nk-egd-nodecards` / `.nk-egd-nodecard` 类名**不改**（卡片同时承载层半场与星启节点，名里的「node」两处都成立；改名要同步约 25 处 e2e 选择器，收益仅是字面）。命名债务记在此处。
- `EndgameTargets.vue`（01/02/03 序号形态）**保留**：层 tab 不再消费它，忘却之庭 / 虚构叙事 / 异相仲裁的层尾目标仍在用。
- `StageHead` / `EndgameFloorBuff` / `StageContent` / `EndgameBuffGroup` 的消费方与缺省形态不变。
- 层目标区新增了星标行渲染（`.nk-egd-startargets`），与星启共用；层目标恒为 `TOTAL_SCORE`，非该类型仍走语义胶囊标签（当前无实例）。
- 详情页无像素基线；本轮 `visual.spec` 未跑（AGENTS 禁全量 e2e）。

## 替代方案

| 方案 | 为何未采用 |
|---|---|
| 保持两个半场纵向排列，只对齐星启的块序与字号（Q1 选项 B） | 用户选 A：同页两个 tab 形态不同构，正是本次要消除的差异 |
| 卡片行只作概览、两个半场仍全渲染（Q1 选项 C） | 首领图 / 推荐属性会在卡片与场次行各写一遍（重复陈述） |
| 挑战目标留在层尾（Q2 选项 B） | 用户选 A：与星启同构，切半场时目标始终在顶 |
| 末法余烬放进每个半场看板内（Q5 选项 B） | 层共用一块内容会随子切换重复出现；星启的「每节点一块」是因为那里每节点各有自己的 buff |
| 末法余烬留在层尾（Q5 选项 C） | 首屏看不到它，且与星启的区块序首尾相反 |
| 首领特性保持「每条一卡」（Q6 选项 B） | 用户选 A：两个 tab 统一为整组单卡 |
| 层标题保留等级（Q9 选项 B / C） | 用户选 A：等级随卡片走，层标题只承担层的身份；两处并写会让同一数字同屏出现三次 |
| 层目标保留「挑战目标」+ 01/02/03 序号（Q10 选项 B） | 用户选 A：与星启同口径（官方文案「星级目标」），同页同一类数据不留两套叫法与两种行式 |
| 保留 `card` / `label` 两个已无消费方的 prop | ADR 0033 已立「撤回做得彻底，不留未消费的 API」；死形态留在组件里会在下一轮被顺手消费 |
| 层 tab 复用 `.nk-egd-tierce__*` 类名但不改名 | 星启专有名出现在层面板里属命名错位；改名只动本页 e2e 的机械引用，且两处消费者同批迁移 |
| 把卡片行抽成「两卡时退化为并列信息条」 | 卡片兼作子切换，退化会制造第二条阅读路径与第二套 e2e 断言 |

## 修订（2026-10-02，用户看过页面后）

用户三条原话：「`document.querySelector("#egd-level-panel > div > header")` 第 1 层 支配遗忘·难度01 这一行 没有价值，移除。」「末法余烬位置改成和星启模式一样。」「星级目标 优化成一行信息。」三项都属展示口径，逐条落在原决策上：

1. **层标题整行移除（改决策 2）**：层名（如「支配遗忘·难度01」）与层级子 tab 的「第 N 层」重复，未发布赛季还整块缺省；面板首块改为星级目标。`.nk-egd-lvl__head` / `__title` / `__name`、手机档的行间距重述与字号收口块里的 `.nk-egd-lvl__name` 条目同批删除——**层名到此没有任何上屏位**，等级仍只在半场卡片上。
2. **末法余烬改随看板（改决策 3 的落点）**：位置与星启看板逐字一致——**看板首块**，块序 末法余烬 → 首领特性 → 敌方配置 → 赛季增益；层 tab 因此只用面板顶部左栏（关卡没有通关奖励）。代价是层共用的一块增益随半场切换重复出现（同屏仍只有一份），换到的是两个 tab 的看板块序完全同形。
3. **星级目标合并为一行（改决策 3 的行式）——随后被用户撤销**：曾用既有的 `fmtDescMerged` 把三/四档参数并进同一句（「获得4000/5200/6600分」）、星标一枚、整块 34px。用户看过页面后的下一条指令即「星级目标 的改动取消掉，不再是一行信息」——**合并成一行后每档的分数不再各占一行，档位之间的递进关系读不出来**，故 `EndgameStarTargets` 恢复逐档一行（每档一枚星标 + 各自一行、靠行距分节），与星启看板原有的行式一致。**该组件现为单一形态，不再有「合并 / 逐档」两条分支**（`fmtDescMerged` 的使用随之退场）。

4. **污染等级徽标只留在看板头（改决策 6 的落点）**：用户在看完页面后点名移除「首领特性那一行右侧的污染等级标识」——原实现把徽标投进 `EndgameTraitGroup` 的 `head-end` 插槽（ADR 0033 决策 4 的截图位），现改为**看板头唯一位置**：`EndgameBoard` 的看板头在 `stage.invasion` 存在时始终渲染，`head-end` 插槽与 `.nk-egd-group__tail` 随最后一个消费方一并删除（不留未消费的 API）。星启看板同步生效（三模式共用同一组件），层 tab 与星启 tab 的徽标落点因此完全一致。

四条都零数据改动（无转换器改动、无产物变化），本 ADR 其余决策（卡片行形态、卡面四项、看板块序、看板缩进与轨宽、死形态清理）不变。
