# 审计与验收档案（docs/audit）

> **定位：审计与验收档案**（多数为历史记录，3 份现行判据 / 流程见清单状态列）。本目录存「当时怎么审、审出什么、按什么判达标」——审计证据与验收判据，不是规则、不是决策、不是坑位。
> 进入方式只有一条：按下方清单**按需读单份**，禁止整目录通读。读任何一份先看文首状态行再往下读。

## 读法

- **按需读单份**：改哪个域读哪一份；「历史记录」的结论只作证据，落地前对一遍它文首标注的现行落位。
- 命中率 / 条数 / UA 名单这类数字是**当时快照**，引用前复核上游（jsDelivr 仓库、厂商官方文档）。
- 实测数字与过程结论不在本目录：在 [docs/memory/](../memory/) 与 commit message。
- 新增审计沿用 `字段审计-<表名>.md` 命名并补进本表；不按月份 / 日期另建目录。
