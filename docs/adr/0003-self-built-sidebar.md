# 自建侧边栏，完全脱离宿主导航

旧版保留宿主侧边栏并用 CSS 换肤（玻璃胶囊形态），内容区以 left:88px 让位。Vue 迁移时在 Shadow DOM 内自建侧边栏，宿主 DOM 100% 隐藏，不再保留任何宿主元素。

**Considered Options**:
- 复用宿主侧边栏 + CSS 换肤（旧方案）：零开发量且导航结构由宿主维护（新页面自动出现），但隐藏规则必须精确排除侧边栏（宿主改 class 名即漏隐藏/误隐藏）；高亮状态由宿主路由控制，与 vue-router 不同步；Standalone 模式下无宿主侧边栏，需额外 mock。
- 自建侧边栏（采纳）：导航结构复用首页 HOME_NAV 数据（8 项），高亮由 vue-router 的 route.path 驱动（~30 行）；响应式行为照搬现有 CSS（桌面=左侧胶囊，≤767px=底部 Tab Bar）。

**Consequences**:
宿主新增页面不会自动出现在我们的导航中——需要手动同步 HOME_NAV 配置。这是「完全自主」原则的有意取舍：宿主改版（无论是结构还是样式）不再能破坏我们的 UI。
