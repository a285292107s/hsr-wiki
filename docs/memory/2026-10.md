# 2026-10 复盘日志

## 「贪饕」污染色：机制语境色进令牌体系（ADR 0027）——**取证推翻了口述色相**

- **用户原话**：「讨论一下颜色的问题。贪饕污染，游戏内有专门的主题颜色，是代表不详的猩红色」。
- **事实核查（决定了整轮边界）**：① 站内**没有任何机制专属色**——`/voracity` 全页（吸顶进度条、secnav 激活项、卡底纹与边框、数值强调位）加怪物详情「受『贪饕』侵蚀」标记、终局污染徽标、目录卡「含污染」标记**全部消费 `--primary`**，即读感等于用户当前强调色（缺省赤陶）；② 数据里**没有权威色值**——教程富文本强调色是全局琥珀 `<color=#f29e38ff>`（且与 `--elem-fire #FF6B35` 几乎同色相），侵蚀 buff 图标是通用 `IconBuffShield`，颜色是这套机制唯一能承载身份的表达；③ 素材取证（子代理，HSV 过滤 `V<0.15/V>0.9/S<0.25` + k-means + WCAG 对比度）得到**红徽记 + 洋红能量并存**：徽记 `#DF3D3D`/`#FF4242`、洋红能量 `#C40C6A`（官方 4.6 公告 KV 内 top1 簇 22.2%）、受污染敌人血条 `#FC48AC`、徽记暗部 `#66030C`。
- **最重要的教训**：**「游戏内有专门的主题颜色」这类需求，用户口述的色相不能照抄**——它可能是记忆里最抓眼的一小块（红色徽记），而画面主体与官方宣发的主体其实是另一支（洋红能量）。取证与口述不一致时必须**当场指出**并把选择交回用户（Q8 卡片），照抄会让页面读成「另一个模式色」的近亲。第二条同源教训：**污染标记恰恰渲染在按模式着色的终局页里**，所以选色的第一道验收是「与 `--eg-boss` 玫瑰红 `#FB7185` 分不分得开」，而不是只看单页观感——纯红族正是因此落选（同色相族、红上加红）。
- **9 项决策走卡片收敛**（Q1–Q9）：新领域语义族 + 页面语境色（一份色值两处身份）/ 从游戏素材取样推导 / 覆盖四个面（`/voracity` 数据元素、怪物详情标记、终局徽标与赛季级区块、目录卡标记）/ 分两档（基准位 + 文字亮端 ≥4.5:1）/ `/voracity` 只染数据面 + 结构强调位（不动 hero 与页面底色）/ 登记为「语境色」类别并补登既有 `--eg-*` / 新增 ADR / 本轮文档 + 实现。
