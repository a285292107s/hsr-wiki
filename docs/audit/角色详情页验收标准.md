# 角色详情页 · 「获奖级品质」验收标准（v1）

> 本文件把用户目标里的主观词（「awwwards / Webby / FWA 能获奖」）落成**可执行、可判定、可复现**的验收项。
> 判据来源：三家奖项的**公开评审维度** + W3C 标准 + 本仓既有的取证工具链（逐字形像素尺子 / 布局取证 / e2e 契约）。
> 本文件只写「用什么判、门槛多少、在哪验证」；**具体实测数字进 commit message 与 `docs/memory/`**，避免双事实源漂移。

## 0. 判据来源（外部，均为公开页面）

| 来源 | 用到的部分 |
| --- | --- |
| [Webby · Judging Criteria](https://www.webbyawards.com/judging-criteria/) | Websites & Mobile Sites 的 7 个维度：Content / Structure and Navigation / Visual Design / Functionality / Interactivity / Innovation / Overall Experience。其中 Visual Design 明写「improving inclusion for people with disabilities…low-vision」；Functionality 明写「cross-platform and browser independent」「special access needs, disabilities, and bandwidth limitations」 |
| [awwwards · Evaluation System](https://www.awwwards.com/about-evaluation/) | 评审团打分制与「Design / Usability / Creativity / Content」四轴（逐项权重以站方公开说明为准；本文件只用其**维度**，不引用未证实的百分比） |
| [FWA](https://thefwa.com/) | 以「作品本身的完成度与创意」为入选主线；本文件只借用其「craft 与 novelty」取向，不设独立量化项 |
| [W3C · Understanding SC 2.5.8 Target Size (Minimum), Level AA](https://w3c.github.io/wcag/understanding/target-size-minimum) | 触控目标 ≥ 24×24 CSS px（本仓历史上按 WCAG 2.2 AA 实现为 44px，更严） |
| WCAG 2.2 | 对比度 4.5:1（正文）/ 3:1（大字 ≥24px 或 ≥18.66px 粗体）、`:focus-visible` 焦点可见 |

**量化门槛一律取「更严或等于」的一句话**：Webby 的维度是定性的，落地时只接受能写出**观测方式 + 阈值 + 复现命令**的判据。

## 2. 验收项（B 类：目前**无观测方式**，达标前不得宣称）

| # | 验收项 | 门槛 | 缺口 |
| --- | --- | --- | --- |
| B1 | 首屏性能 | LCP ≤ 2.5s / CLS ≤ 0.1 / INP ≤ 200ms（Core Web Vitals 2024），**或明示降级为可断言代理指标** | **已实测 + 明示降级**。实测（dev server，Performance API，4 视口 × 3 角色 × 3 次）：**LCP 中位 468~788ms**（最大元素 = `.nk-hero__bg`）、**CLS 最大 0.0107（14 次里 9 次为 0）**，两项均远低于门槛；INP 未测（headless 合成事件无代表性）。**代理指标（正式接受为验收项）**：e2e「骨架态与就绪态 hero 面板同宽同高（±1px）」——它锁住本页最大的潜在位移（骨架→就绪替换），盒高取自全量 98 只角色的中位数。**残留已记录**：加载期 0.006~0.009 的亚感知位移，根因是异步布局稳定（非骨架不一致）；`scrollbar-gutter: stable`（`html` / 滚动容器两处）**实测无效**，故未采用 |
| B2 | WCAG 2.2 AA 全量 | axe 以 **2.2 AA 规则集**扫描且零 serious/critical | **已升级**：`e2e/accessibility.spec.ts` 显式传 `withTags(['wcag2a','wcag2aa','wcag21a','wcag21aa','wcag22a','wcag22aa'])`，并补了一条 390×844 手机档用例（该文件被 mobile 项目 `testIgnore` 排除 ⇒ 手机独有的对比度路径此前未被扫过）。角色页 390/1440 实测 0 违规（含 best-practice） |
| B3 | 跨浏览器 | Firefox / WebKit 至少一次对照取证，差异有结论 | **已取证并修出一个真缺陷**。三引擎对照（2 视口 × 契约子集）：标题语义 / hero 面板落位 / 主字分档 / 素材对位 / 横向溢出 / 焦点可见 / `:has()` / `mask-image` **全部一致**；**唯一差异 = 滚动驱动视差**——Firefox 不支持 `animation-timeline`，缺 `@supports` 门时动画退回普通时间轴跑完停在末帧（`fill: both`）⇒ 媒体层**永久下移 36px**（构图位移，不是「少个动效」）。已加 `@supports (animation-timeline: scroll())` 门：不支持 ⇒ 静态构图（实测修后 Firefox `translateY` 恒 0，chromium/webkit 0→17.1→36）。**入常规回归（2026-10 收窄）**：`firefox-layout-contract` 项目只收集打了 `@cross-engine` 的用例（10 条：hero 结构与素材对位、文字可读性（字形软影）、卷宗标题语义、骨架↔就绪同框（CI 下再被 `@font-calibrated` 收起）、1024 与矮横屏面板落位、滚动视差、吸顶导航 mask 横滑、键盘焦点环、极端视口矩阵）。**收窄理由**：该项目原为 39 条全量重跑，实测独占全量墙钟 46%（末段只有 1 个 worker 在跑），而真正判引擎差异的只有上述几条。**未覆盖并明示**：① firefox 不再重跑的角色详情页其余布局用例（纯几何 / 数据断言，语义与引擎无关，由 chromium 承担）；② WebKit 与其余 spec 未入 CI（避免三引擎 × 全量的墙钟膨胀），WebKit 以一次性人工对照取证 |
| B4 | 跨视口 | 320 → 2560 + 矮横屏 + 竖屏全覆盖，逐档无破版 | **已建矩阵**：12 视口 × 4 角色铺量（320×568 / 360×800 / 390×844 / 414×896 / 768×1024 / 834×1112 / 1024×768 / 1280×720 / 1440×900 / 1440×460 矮横屏 / 1920×1080 / 2560×1440）；不变量层固化为 e2e「极端视口矩阵」一条（hero 面板完整在内 / 主字单行 / 章标 ≥ 最大正文 / 无未知横向溢出）。铺量结果：唯一命中的越界是**既有已定性的 Spine 画布**（1.15 缩放越出容器、被祖先裁掉） |
| B5 | 结构化数据 | 可索引详情页含与页面实体类型相符的 `schema.org` 标注（不是无差别 `Article`） | **已实现**：角色详情页 JSON-LD 由 `Article` 改为「`WebPage` + `mainEntity` = `Person`（角色本体）+ `BreadcrumbList`」，角色属性走 `Person.characterAttribute`（schema.org 对该属性的定义即「虚构角色的某项数据：技能/能力/点数/优劣」），拉丁转写名走 `alternateName`（空则整键省略）。形状断言进 `tools/check-ai-endpoints.mjs`（含反向验证：把 `Person` 改成 `Article` 会判红） |

## 3. 验收项（C 类：外部不可控，**明确排除**，不写进目标）

- 实际获奖结果（评审团主观与当期竞争态势）；
- 「视觉惊艳 / 一眼记住」等主观观感 → **交用户 RunPreview 裁决**，AI 不输出此类结论；
- 与目标页无关的板块（侧栏导航、其他详情页）——本页作用域外。

## 4. 结论规则

1. **达标** = A 类全绿 + B 类全绿 + C 类已按上面口径排除。任一 A 类红即未达标。
2. **降级必须显式**：A2 这类「接受少量不达标」的口径必须在本文件与 `docs/memory` 同时可见，且写明最坏值与样本量；只改代码不改口径视为未达标。
3. **推翻仓库设计规范**（用户 2026-10 授权）：允许，但须记录「推翻了哪条 + 为什么 + 替代判据」，且替代判据必须落在本文件的 A 类里（可观测、可复现）。
4. 本文件的**唯一数字事实源**仍是 `docs/memory/` 与 e2e 契约；本文件只登记「判什么」，不登记「实测多少」。
