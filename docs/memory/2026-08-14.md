## 虚拟网格动画测量假象（探针返工 ≥2 轮的根因）
- 现象：溢出检测显示 36/36 卡均匀 +4px 溢出；hover 阴影捕获到全透明中间帧。
- 根因链：① 卡片入场动画 `nk-card-in`（from translateY(14px)）+ `backwards` 填充 → 动画 delay 期/滚动未 reveal 的卡片恒为 `opacity:0 + translateY(14px)`，`getBoundingClientRect().bottom` 多出 14px（-10 padding = +4 假象）；② `[].every(...)` 对空数组恒 true → waitForFunction 秒过（跳过所有未归位卡片后条件恒真）。
- 处置（已验证）：溢出统计必须过滤 `opacity==='1' && transform==='none'` 的卡片；等待条件必须带 `visible.length >= N` 前缀（防空数组）；hover 断言等阴影 alpha 特征（0.2/0.45）而非 `!== 'none'`（杜绝中间帧）。
- **坑位**：虚拟网格首屏稳定 reveal 数 < 视口卡片总数（IntersectionObserver threshold 0.5，缓冲行不触发）——等待门槛不得高于稳定值（桌面 1440×900 为 18 张、手机 375 为全量 10 张）。
