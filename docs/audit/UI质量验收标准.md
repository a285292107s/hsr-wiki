> **本文件回答「做到什么程度算达成」**：[ui-design.md](../agents/ui-design.md) 回答「怎么做」、[verification.md](../agents/verification.md) 回答「怎么取证」。

> 页面级实例见 [角色详情页验收标准.md](角色详情页验收标准.md)（本文件是它的全站上位口径，冲突以本文件为准）。

> **取证状态口径**：`✅部分` = 有载体但只覆盖子集（**必须写明规模**）；`待建` = 连载体都没有。`✅部分` 不得据此宣称该条达标。
> **维护规则**：门禁一旦建立，表内「起点基线」数字（现状统计 / 实测值）**必须删掉**——留着即毒化上下文；过程结论归 commit message。

## 1. 先裁剪：本站是哪种作品

奖项口径隐含「品牌互动站」形态（3D、音效、滚动叙事、一次性记忆点）。**本站是档案型数据站**，照搬会与既有裁决冲突并伤害 usability ⇒ 四项不采纳：全屏媒体层 / 立绘轮播 / 枢纽滚轮 / 滚动劫持（**ADR 0018 / 0019 明令禁止，不因评奖回改**）、3D / WebGL / WebGPU（预渲染快照 + 低带宽受众，收益与代价倒挂）、音效与音频编排（无静音开关先例）、装饰性动效堆叠（[ui-design.md](../agents/ui-design.md) §7）。

**投入面优先级**（由本站类型修正）：① **Design 一致性**（外部点名的失败模式是「首页精致、内页像另一个站」；本站风险在字号 / 圆角跨家族无共同基座）；② **Usability**（性能 / CWV / WCAG 2.2 新增项 / 320px 与 200% 缩放，均可自动断言）；③ **Creativity 用站内自有资产兑现**（Spine 预览、虚拟滚动目录、跨模式、终局四玩法同构骨架），不新造特效；④ **Content 已是强项**（真实解包数据、零占位），守住不回退。

| --- | --- | --- |
| P0 硬裁切 | 文字被容器吃掉或压到相邻元素上（`overflow: hidden` 且墨迹越界；`nowrap` + `overflow: visible` 横向外溢） | 既看不到也读不到 ⇒ 修到 0，无豁免 |

## 3. B 层：用户裁决（AI 只备证据，不判审美）

每条要求**一份可指认的证据**（截图 / 对比图 / 录屏）与**一次用户勾选**；AI 不得自行给出「达标」结论（职责边界见 [verification.md](../agents/verification.md)）。

| # | 判据（对应奖项维度） | AI 需准备的证据 | 三档 |
| --- | --- | --- | --- |
| B1 | 视觉识别度：一套语言贯穿全站（Design） | 同一元素类别在 ≥6 类页面上的并排截图 | 不一致 / 同类一致 / 跨类一致且有节奏变化 |
| B2 | 一次性记忆点：有没有让人停下来的交互或形态（Creativity） | 该交互录屏 + 与常规页面对比 | 无 / 有但只是动效 / 有且服务于内容 |
| B3 | 微交互品质：hover / focus / press / 禁用态齐全且克制 | 同一控件四态截图组 | 缺失 / 齐全 / 齐全且有物理反馈 |
| B4 | 动效编排：有意图、有节奏、可打断、尊重 reduced-motion | 动效序列帧表 / 录屏 | 装饰性 / 有意图 / 有编排且不阻塞操作 |
| B5 | 密度与留白：信息密度与呼吸感 | 首页 / 目录 / 详情 / 长文四类首屏对比 | 拥挤或空旷 / 可读 / 有明确节奏 |
| B6 | 文案语气：档案语气一致、无营销腔 | 标题/说明/空态/错误态抽样 | 混杂 / 一致 / 一致且有声音 |

## 4. 达标定义（终止条件）

1. **硬条件**：A 层全绿——每个 A 项都有可重复执行的取证且最近一次执行全绿。
2. **软条件**：B 层 6 项各有可指认证据，用户判定 ≥目标档。
3. **一票否决**（命中即判未达标）：为评奖推翻 ADR 0018/0019 禁项；引入模板化/生成式痕迹；桌面优先、移动端后补；首页精致而内页像另一个站；首屏有占位内容；性能靠「以后优化」。
4. **推进顺序**：A4 设计系统一致性 → A3 性能 → A2 可访问性缺口 → B2 记忆点 → 其余。
5. **降级必须显式**：任何「接受不达标」的口径要同时出现在本文件与 `docs/memory/`，写清最坏值与样本量；只改代码不改口径视为未达标。
