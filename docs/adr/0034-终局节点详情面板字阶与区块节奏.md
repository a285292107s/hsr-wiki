# 0034. 终局节点详情面板的字阶、区块节奏与标签形态

## 状态

`accepted`（**已实现**：`endgame-detail.css` 的字档收口块重写——区块标题由 `0.68rem`/字距 `0.14em`/`--text3` 提到 **`0.78rem`/字距 `0.06em`/`--text-bright`**，压在它所统领的正文（`0.84rem`）之上；星启看板体区块间距 `14 → 24px`（手机 `12 → 20px`）；`.nk-egd-group__head` 加**下沿发丝线**作为区块分节；**六处填充胶囊去填充**（`.nk-egd-group__label` / `.nk-egd-tierce__headlabel` / `.nk-egd-floor__moncount` / `.nk-egd-floor__summarydata` / `.nk-egd-node__type` / `.nk-egd-pollchip`），首领特性标签行由药丸胶囊改**发丝线 + 骑线模式色下划线**，敌方卡的 `__tag` / `__rank` 由 `999px` 收到 `4px`；`.nk-egd-children` 缩进竖轨在看板体上由**失效改为生效**（实测 `padding-left: 16px` + `3px` 竖轨）。**修订 [ADR 0033](0033-星启模式改单节点看板.md) 决策 6 的「胶囊标签原语」命名与形态**（类名 `.nk-egd-pilltabs`/`.nk-egd-pilltab` 保留以维持 e2e 选择器与三处复用，但不再是胶囊））

## 背景

用户对末日幻影 **星启模式每个节点的详情面板**给出三条要求：**反 AI 味、信息层级清晰、字体大小与元素间距合理**。改动前对 `/endgame/boss/3020` 星启看板做了计算样式取证，五处问题都有实测数值：

1. **字阶倒挂（最严重）**：区块标题「首领特性」「赛季增益」是 **11.52px**（`0.72rem` 档之后又被后段收口块压到 `0.68rem`），而它统领的正文是 **13.44px** —— **页面里最小的字是最外层标题**。同一看板里节点号 16px、卡面 15.2px、末法余烬名 15.2px、正文 13.44px —— 四档标题性文案各自为政，没有一条能读出「谁包着谁」。
2. **看板体缩进失效**：`.nk-egd-tierce__nodebody` 挂着 `.nk-egd-children`（ADR 0028 的缩进与竖轨唯一声明处），实测 `padding-left: 0px`、`::before` 宽度 `0px` —— 缩进从未生效，看板体与上方卡片行左边界齐平，层级刻度在看板这条分支上等于没有。
3. **区块节奏不成比例**：四个区块间距实测 124 / 144 / 135 / 109px（差异来自各卡自身内距），且**有末法余烬的节点与没有的节点规则不同**（节点三整块退场时缺口直接从行头开始），读者读不出「哪些是同级区块」。
4. **999px 填充胶囊在面板内出现五层**：面板头部两个栏名、波次·敌数、首领特性标签行、污染等级徽标、敌方卡标签 —— 同一种圆角药丸反复出现，正是 [ui-design.md](../agents/ui-design.md) §7 列为机器感来源的形态；且项目已有「发丝线取代装饰分隔」的既有语言未被复用。
5. **正文行高与字号失配**：正文 13.44px 行高 24.19px（**1.8**）—— 单行短句的块里显得空，而标签档只有 11.52px 且字距 0.14em，两者之间没有中间档，眼睛无法靠字重/字号建立层级。

## 决策

1. **区块标题必须高于它所统领的正文**：`.nk-egd-group__title` = `0.78rem` / `700` / `--text-bright` / 字距 `0.06em`。原「`0.68rem` + 字距 `0.14em` + `--text3`」的形态是把标题当**注脚**用；终局页正文字号是 `0.84rem`，标题低于它就属层级倒挂。字距从 `0.14em` 收到 `0.06em` 是同一决定的一半——CJK 标题不需要靠拉字距制造「标签感」。
2. **字档单点收口**：所有字号只在 `endgame-detail.css` 末尾的「排版刻度收口」块声明一次，并新增两条**相对序硬约束**写进注释——区块标题 > 正文 > 标签档。此前同一个选择器在文件前段（声明）+ 末段（收口块）各写一次字号，前段永远被末段覆盖 = 静默死代码（本轮踩到：看板行头的字号在文件前段声明后整块失效）。
3. **看板体挂 `.nk-egd-children` 即生效**：节点体整块走 ADR 0028 的缩进与竖轨（`--eg-indent: 16px`，<768px `12px`），行头与下方区块共用同一条左基准与竖轨。（**竖轨部分随后被撤销**：星启看板体按用户裁决不画这条模式色轨（轨宽归零），**缩进与左基准保留**——见 [ADR 0033](0033-星启模式改单节点看板.md) 决策 13。）
4. **区块节奏统一为 24px（手机 20px）**：同一面板内所有同级区块用同一个间距，**区块数与内容无关**（当年取证时节点三整块没有末法余烬，其余区块间距不变即由本条保证；该节点已于 [ADR 0032](0032-星启节点按完整场次渲染.md) 2026-10-02 修订补上末法余烬，判据不变）；区块之间的语义由 ① `gap` ② 区块标题下的**发丝线** ③ `.nk-egd-group__head` 的下边线共同承担，不再依赖各卡自身内距凑出的差异。
5. **分节用「小字标签 + 发丝线」，不用填充胶囊**：`.nk-egd-group__head` 加 `padding-bottom: 8px` + `border-bottom: 1px var(--line-2)`；面板头部两栏的栏名（星级目标 / 通关奖励）改 `0.66rem`/`700`/模式色 + 模式色发丝下边线；首领特性标签行改「一条底边发丝线 + 激活项骑线的 2px 模式色下划线」——**与页内既有的 `.nk-egd-tabs` 同一语言**（ADR 0030 已用它，只是没铺到面板内部）。（**该标签行随后由 [ADR 0033](0033-星启模式改单节点看板.md) 决策 12 整体下线**：星启看板首领特性改为整组单卡平铺，本条里只剩区组标题下沿发丝线与面板两栏栏名两项仍然生效。）
6. **胶囊只保留在「页面级状态/模式标识」**：`.nk-egd-hero__status` / `.nk-egd-hero__sid` 与异相仲裁的 `.nk-egd-peak__*`（另一场景、非本轮范围）保持原状；**面板内容区内的五处填充胶囊全部去填充**。去填充后各自靠字号、字距与颜色承担辨识度，污染等级靠 `--vor-300` 文字色（语义色本身即区分度，不靠底纹）。
7. **敌方卡的标签不再用药丸**：`.nk-egd-mon__tag` / `.nk-egd-mon__rank` 由 `border-radius: 999px` 收到 `4px` —— 它们是嵌在卡内的元信息小片，不是可点标签，圆角从「胶囊」降到「方角」即退出机器感形态，无需改结构。

## 后果

**正面**

- 字阶读出层级：卡片节点号 `0.95rem` > 区块标题 `0.78rem` > 正文 `0.84rem` 的**标签档与数值档**各归其位（`0.72` / `0.68` / `0.62`），标题不再是最小的字。
- 「小字标签 + 发丝线」的分节方式与页面既有语言（`.nk-egd-tabs` 下划线、层尾目标行的去线判据、ADR 0028 竖轨）同源，面板内部不再是另一套视觉方言。
- 区块间距在所有节点上一致（24 / 手机 20px），有末法余烬的节点与没有的节点节奏同为可预期（当年取证时节点三属后者，该节点已于 [ADR 0032](0032-星启节点按完整场次渲染.md) 2026-10-02 修订补上末法余烬）。
- 看板的缩进竖轨从「声明了但失效」变成真正生效（实测 `padding-left: 16px`、轨宽 `3px`），ADR 0028 的刻度在星启分支上第一次成立。

**负面**

- **`.nk-egd-group__title` 与 `.nk-egd-group__label` 的形态是共享的**：两个类在 `EndgameBuffGroup` / `EndgameTraitGroup` 内同时消费，故层 tab、异相仲裁的增益与特性区块标题一并被抬到 `0.78rem` 并加了下沿发丝线——这是「同一组件不给两套版式」的代价，不是可局部回退的项。
- 去填充后**污染等级徽标的可辨识度只靠颜色**：`--vor-300` 文字色 + 模式色上下文区分。若后续要求更强的状态感（如 `[data-level]` 分级着色），回退点是给 `.nk-egd-pollchip` 补回左侧 2px 色条或 `4px` 淡底，而不是恢复药丸。
- 敌方卡标签从胶囊改方角后，卡内元信息（阵营 / 韧性 / 速度）与「弱点」行的小图标在观感上更接近，层级靠间距而非形状区分。
- 正文行高 `1.8` 未改：本轮只动字号与区块节奏，未改行高——**单行短句仍会觉得松**，若要收紧属另一类裁定（改行高会同时影响全部长描述，风险面更大）。

**中性**

- 本轮**未改 DOM 结构、未改数据**（零转换器改动、零产物变化）：`EndgameTierce.vue` 的模板变更是把「看板行头升级为唯一节点头」的方案**实现后又按用户裁决整体撤回**（见下「实施记事」），最终形态与 ADR 0033 一致；`StageContent` / `EnemyCard` 本轮新增的 `hideTitle` 一并撤回，不留未消费的 prop。
- `.nk-egd-tierce__monscount`（行头的波次·敌数独立类）随撤回退场，波次·敌数回到 `.nk-egd-floor__moncount`（原渲染位不变；**该渲染位随后在 [ADR 0033](0033-星启模式改单节点看板.md) 决策 11 随行头整块退场**）。
- 类名 `.nk-egd-pilltabs` / `.nk-egd-pilltab` 与 ADR 0033 的字面（「胶囊标签原语」）已不符，但**不改名**：改名要同步 `e2e/layout.spec.ts` 的选择器与三处消费者，收益仅是字面准确；命名债务记在此处。（**该债务已随 [ADR 0033](0033-星启模式改单节点看板.md) 决策 12 消失**：标签行形态下线，两处类名声明与字号收口块里的条目一并删除。）
- AI 快照不受影响（星启在快照里只占一行，字段零变化）；详情页无像素基线。

## 替代方案

| 方案 | 为何未采用 |
|---|---|
| 只把区块标题字号提到正文之上，其余不动 | 用户同时指出「元素间距」——字阶与节奏是同一问题的两面；单独改字号后，124/144/135/109 的不成比例间距仍在，且失效的缩进竖轨仍在 |
| 区块标题改用 `--eg-color` 模式色加粗 | 看板内已有模式色承担激活态（首领特性标签、节点卡选中态、区块标签）；标题再上色会与激活态混淆。标题用 `--text-bright`（最亮中性）承担层级，颜色留给交互态 |
| 区块之间画横向分隔线 | 与「同级只读条目靠行距分行、不画装饰线」的既有判据（ADR 0033 决策 5 同批裁决）相抵；发丝线只出现在**标题下沿**（分节），不出现在区块之间 |
| 污染等级徽标恢复填充胶囊以保可辨识度 | 用户明确要求去掉填充胶囊；语义色文字 + 模式色上下文已足够区分 |
| 把星启面板的排版规则写成页面级覆盖，不动共享的 `.nk-egd-group__title` | 会把同一组件劈成两套版式；用户要求的是「每个节点的详情面板」信息层级清晰，共享件一并收敛更省后续重复 |
| 看板行头升级为「首领立绘 + 首领名 + 等级 + 推荐属性」的唯一节点头（实现后撤回） | 实测实现并截图后，**用户裁决取消**：节点卡片行已承载「打谁 / 什么属性 / 多少级」，行头再复述一遍使切换行与看板首屏重复陈述同一组事实，观感不理想。最终保留 ADR 0033 的形态（行头只留节点号 + 波次·敌数；**该形态随后也被 [ADR 0033](0033-星启模式改单节点看板.md) 决策 11 整体删除**），层级改由**字号与区块节奏**承担 |

## 实施记事（可复用的三个坑）

- **CSS 收口块会静默吃掉前段声明**：本文件末尾有一段「排版刻度收口」块（在 `max-width: 767px` 之后追加），它在**同特异性**下永远覆盖文件前段的字号声明。本轮在看板行头附近声明了字号，实测仍是旧值——**改字号前先 grep 同一选择器在文件里出现几次**；`grep -n "选择器" file.css` 一行就能避开的返工，比重新取证便宜得多。
- **`.nk-egd-children` 挂对了类不等于生效**：它的缩进写在 `padding-left` 上，实测却是 `0px` —— 说明有同特异性规则在后面把它重置。**挂类之后要用 `getComputedStyle` 实测而不是读源码**；「声明存在」与「计算值生效」是两件事，本项目已有 [ui-design.md](../agents/ui-design.md) §4 的同类教训（守卫全绿 ≠ 语法正确）。
- **断点相关的断言不能写绝对像素**：同一条 e2e 用例在桌面与手机两个 project 下跑，字号在断点块里降过一档（如 `1.02rem → 0.96rem`），写死 `16.32px` 会在手机 project 上失败。**层级类断言一律取相对序**（`parseFloat(getComputedStyle(...).fontSize)` 后比大小），既跨断点成立，又恰好锁住「标题不高于正文」这条真正的契约。
