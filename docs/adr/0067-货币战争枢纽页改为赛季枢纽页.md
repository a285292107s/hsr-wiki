# 0067. 货币战争枢纽页改为「赛季枢纽」页：按赛季展示主题

> **取代** [ADR 0020](0020-货币战争枢纽页改为本赛季新增页.md) 的页面形态与展示口径（「本赛季新增」叙事已于 2026-11-18 退役）。0020 的**数据判据**结论继续有效：货币战争按赛季（代）而非小版本划分，官方无「赛季 1.1」粒度。本文只改**枢纽页讲什么、怎么讲**，不改五个图鉴页的赛季筛选口径。
> **不回落** [ADR 0018](0018-枢纽页改为工具化入口页.md) 的禁止项（全屏媒体层 / 背景视频 / 立绘轮播 / 枢纽滚轮）与 [ADR 0019](0019-枢纽页导航条回归与首页改为版本上新页.md) 的「两枢纽全断点渲染导航条」。

## 状态

`accepted`（**已实现**：新转换器 `tools/converter/converters/currency_seasons.py` → `public/data/cn/currency/seasons.json`；`use-cw-season` 参数化按季构建 + `seasons`/`seasonScale`/`selectSeason`；重写 `CurrencyHubView.vue` 顶部时间线 + 主题板块；`currency-hub.css` 时间线/主题样式；11 个新 UI 词典键 × 13 语言 + `nav.currencyHub*` 改名；`gen-ai-endpoints.mjs` 赛季化枢纽快照；`e2e/layout-currency.spec.ts` 改写。`pnpm build` 七守卫 + AI 端点守卫 exit 0，`pnpm test` 649 通过，`layout-currency` 18/18 e2e 通过）。

## 背景

枢纽页（`/currency`）当前自称「枢纽」，实际展示的是**单一当前季**的角色 / 羁绊 / 装备 / 环境 / 策略全量长卷，赛季号只作为印记里一个数字（`第 2 赛季`）出现。三个问题：

1. **页面没有「赛季」这个主角**。货币战争的骨架就是「一季一主题玩法 + 一套角色与羁绊」，但页面从未展示赛季的官方名（货币战争•零和博弈 / 货币战争•入画奇航）、也没有展示每季的主题玩法（奇遇伙伴 / 主角光环 / 赛季天赋）。
2. **官方赛季名根本不在产物里**。历史文档把「赛季名」标为需从 TextMap 重新抽取（[货币战争赛季切换-可行性分析 §注](../audit/货币战争赛季切换-可行性分析.md)）。实测存在**确定性链路**：`GridFightSeasonModule.ActivityModuleID` → `ActivityConfig` → `ActivityPanel.TitleName` / `PanelDesc`，每季都有官方名与一段官方简介，可零手写抽取。
3. **页首 tagline 是过时文案**：「赢者通吃的零和博弈……」写的是**第 1 赛季**主题，而默认展示的是第 2 赛季（入画奇航）。按赛季展示主题顺带修正这处内容错位。

## 决策

1. **页面改名为「赛季枢纽」**（`nav.currencyHub` / `nav.currencyHubShort` 与 `<h1>`、`document.title`、AI 快照标题同源）。路由与 `meta.cw` 不变。
2. **以「赛季时间线 + 选中赛季详情」为骨架**：
   - **顶部时间线**：每季一张可选卡（`button.nk-cwsc-season`），含赛季号、官方名、官方简介、当期角色数与羁绊数（`seasonScale`）、小赛季数、`当前赛季` 徽标；点击即切换下方详情，`aria-pressed` 标选中，选中态存 `localStorage`（沿用 `HSR_WIKI_CW_SEASON`）。
   - **主题玩法板块**：展示选中季的 `themes`（奇遇伙伴含成员名、主角光环计数、赛季天赋计数）；某季无主题（如赛季 1）显示一行说明而非空白。
   - **本季速览长卷**：保留原「启幕 / 板块 / 名册 / 账房」四幕，作为选中季的速览，随赛季切换重建（数据层 `use-cw-season` 以 `cwSeason` 参数驱动 `fetchData`）。
3. **新增转换器 `currency_seasons.py` 产出 `currency/seasons.json`**：`{current_season, seasons:[{id, name, desc, sub_season_ids, themes[]}]}`，文本走 `$t:` 令牌（13 语言包自动生成）。名/简介取 `ActivityPanel`；主题玩法计数按**赛季归属**统计（奇遇按角色赛季、光环按可选角色赛季去重、天赋按自带 `SeasonID`）。判据细节见 [转换器字段映射 · currency_seasons.py](../data/转换器字段映射.md)。
4. **主题只上屏「名称 + 计数」（+ 奇遇成员名），不引入主题图标**：图标镜像未覆盖 `Quest/**`（`SpriteOutput/Quest/TabIcon/**`、`Quest/ChimeraDuel/**`），新增镜像等于开辟一条新图管线；主题用文本+计数已能表达，不为此扩图管线。
5. **AI 快照改为赛季化**：`/currency` 快照列出全部赛季（名 + 当前标记 + 简介），再给当前季的主题玩法与当期角色 / 羁绊清单；标题与客户端一致（`赛季枢纽 - 崩坏：星穹铁道 Wiki | 星铁档案馆`）。服务端仍以「当前赛季」为默认内容（交互用户可在客户端切季；快照不随交互变）。

## 备选与放弃

- **每季一张完整大卡纵排（无选中交互）**：页面更长、无法聚焦单季详情，且与「时间线」相比只是把四幕复制 N 份；放弃。
- **极简赛季档案（删四幕长卷）**：改动最小但丢掉已有的角色 / 羁绊 / 装备速览，信息密度倒退；放弃。
- **手工在词典里写死赛季名与简介**：违反「展示文本必须来自数据源」，且每出新季就要人工改代码；放弃，改走 `ActivityPanel` 抽取。
